## Statement

There is a rank-three thirteen-site complete lattice base $P\subset\mathbb Z^3$ with seven occupied parities and a positive width vector $w$ of total one, given below, satisfying every anchored width inequality and every strict proper closed-minor quota
$w(T)<k(T)/7$ for nonempty proper $T=P\cap\operatorname{conv}T$, where $k(T)$ counts its occupied parities. There are $110$ nontrivial extreme anchored representations, $22$ tight rows of rank seven, and $1999$ nonempty proper closed minors with minimum quota margin $1/65$. The compatible center space has local dimension six at zero and the affine center subspace has dimension four.

For every $d\ge1$ and $0<\varepsilon<1/2$, the compatible boxes of widths $w_i$ and first-coordinate centers $c_i=\varepsilon w_i$ yield an actual convex body with all these quotas. Its centroid graph has relative Helly number at least nine, with deletion hulls from indices $3,4,\ldots,11$. The centroid graph is nonaffine and tends in Hausdorff distance to the affine zero graph as $\varepsilon\downarrow0$.

The following exact finite enumeration verifies the base census, inequalities and tight supports. For every subset $J$ of indices of size $m\in\{2,3,4\}$, form the matrix $A_J$ with columns $(1,p_j)$ for $j\in J$. Skip a subset if its columns are dependent. Choose any nonsingular $m$-row minor and solve it over the rationals for the corresponding components of $(1,q)$. Record the support and coefficients exactly when the solution is strictly positive and satisfies all four rows. For lattice completeness test every $q$ in the integer box $[-1,2]\times[-2,3]\times[-1,2]$ outside $P$. The procedure returns no representation of any such point. All points of the hull lie in this box. If a point is in the hull, an extreme coefficient vector on the simplex of coefficients has independent columns, since otherwise a nonzero kernel direction preserves feasibility for small motions in both signs. Conversely each positive solution with independent columns is extreme by its uniqueness on that support. A support of size one gives only its existing base point. This justifies exhaustive coverage, both for the integer hull test and for the anchored enumeration. For a target in $P$, an extreme support containing the target is its singleton, so exclude it from the nontrivial count.

Run the same support test with $q=p_i$ and $i\notin J$. The per-target nontrivial counts in order are $0,0,9,16,19,21,24,1,19,0,0,1,0$. Each row has $w_i-\sum_j\lambda_jw_j\ge0$. Keeping its zeros gives the following complete list of tight supports, with absent targets having none.

| target | tight supports |
| --- | --- |
| 2 | $\{1,3\},\{1,4\},\{0,1,5\},\{0,1,7,10\}$ |
| 3 | $\{1,4\},\{2,4\},\{0,1,5\},\{0,2,5\},\{0,1,7,10\},\{0,2,7,10\}$ |
| 4 | $\{0,5\},\{0,1,7,10\},\{0,2,7,10\},\{0,3,7,10\}$ |

These entries can be reproduced by subtracting $\sum_j\lambda_j(43680 w_j)$ from $43680 w_i$ in the support loop. Gaussian elimination over the rationals on the rows $e_i-\sum_j\lambda_je_j$ of this table gives rank seven. The augmented base rows $(1,p_i)$ have rank four and the residues $p_i\bmod2$ have seven distinct values. For the proper-minor check, loop over nonzero proper thirteen-bit masks $m$. Reject a mask if it contains a recorded nontrivial base support for some omitted target. This tests closedness exactly by the independent-support criterion. For each retained mask, compute the number $k(m)$ of distinct parity residues and subtract the sum of its integer weight numerators from $6240k(m)$. This leaves $1999$ masks and minimum numerator $672$, attained in particular at the singleton $\{7\}$. Dividing by $43680$ gives $1/65$. The positive integer numerators sum to $43680$. Apply the compatible-center lemma to obtain local dimension $13-7=6$, while restrictions of affine scalar functions on the rank-three base have dimension four.

For $c_i=\varepsilon w_i$, the absolute center gap of each anchored row is exactly $\varepsilon$ times its nonnegative width slack. The compatible-center lemma gives all integer fibers as prescribed. The hull is full-dimensional because the projection spans $\mathbb R^3$ and every box has positive $d$-volume. The weights are exactly the actual box volumes. Since $p_5=(p_2+p_{11})/2$ but $w_5-(w_2+w_{11})/2=19/7280$, the centroid graph is nonaffine for $\varepsilon>0$. Its convergence to the zero graph follows from finiteness and $c_i\to0$.

The graph is affinely identified with $G=\{(p_i,w_i):0\le i\le12\}$ by dividing its first continuous coordinate by $\varepsilon$. For a target outside a proposed generating set, a graph convex representation gives a base representation of zero width slack. Decomposing its coefficient vector into extreme vectors uses only extreme supports from the given set, since the coordinates are nonnegative and zero coordinates of the original vector stay zero in each positive summand. Each extreme vector has nonnegative slack, so every summand used must be tight. Conversely a tight extreme vector supported in the set gives a graph representation. Thus the tight-support table exactly tests graph convex-hull membership outside the generating set.

Put $I=\{3,\ldots,11\}$ and $W=\{(p_i,w_i):i\in I\}$. None of the tight supports in the table is contained in $I$. For targets in $I$ this excludes membership in the hull of the other points of $W$, and for targets outside $I$ it excludes membership in $\operatorname{conv}W$. For each $i\in I$ use the convex set $\operatorname{conv}(W\setminus\{(p_i,w_i)\})$. Omitting any one set leaves its deleted point in all the others. Their full intersection contains no graph point, since only points of $W$ can lie in $\operatorname{conv}W$, and each is excluded from its own deletion hull. This gives the nine-set witness.
