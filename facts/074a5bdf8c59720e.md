## Statement

Let $P\subset\mathbb Z^n$ be finite, nonempty and lattice-complete, and fix a complete simplicial fan in $\mathbb R^d$, $d\ge1$, with ray generators $u_r$. For each $z\in P$ and maximal cone $\sigma$, the proposed ray values $h_{zr}$ specify a unique linear piece $u\mapsto u\cdot v_{z,\sigma}$ on $\sigma$. These pieces give the actual support functions of the prescribed sampled fibers of a compact convex hull if and only if
$$
h_{zr}-u_r\cdot v_{z,\sigma}\ge0,\qquad
h_{qr}-\sum_z\lambda_z h_{zr}\ge0
$$
for every relevant $z,\sigma,r$ in the first inequality and every $q,r$ and vertex $\lambda$ of its anchored representation polytope in the second. The supports may be those of lower-dimensional fibers. Denote the resulting linear row matrix by $A$ and the active rows at a feasible array $h$ by $I$.

The radial tangent cone and the velocities at zero of differentiable two-sided feasible paths are respectively $\{v:A_Iv\ge0\}$ and $\{v:A_Iv=0\}$. Every velocity in the latter set is realized by $h+tv$ for both signs of sufficiently small $t$. For such $v$, the path $h+tv+t^2w/2$ is feasible for both signs near zero exactly when $A_Iw\ge0$. If the original fibers have positive $d$-volume, they remain positive in all sufficiently small feasible perturbations. A new facet can appear along a two-sided differentiable path with zero first velocity.

## Proof

The linear pieces agree on shared faces because those faces are generated by common rays. Under the first set of constraints each piece lies below the assembled function on every ray, and hence on every cone by linearity. The function is thus the maximum of the pieces and is the support function of $\operatorname{conv}\{v_{z,\sigma}\}_\sigma$. Conversely if a function is a support and agrees on the interior of a full-dimensional cone with $u\cdot v$, then $v$ is a point in the supported body. To see this, at an interior direction choose any maximizing point and test its scalar product after small perturbations of that direction in both signs. It must agree with $v$ in each coordinate. Its linear form lies below the support on every ray. The second set of constraints extends over each cone and over all anchored weights by linearity. Fact ba0f3db1bf4f62c6 gives exactly the stated hull sections.

For every inactive row at $h$ there is positive slack and there are finitely many such rows. The sign of an active row along $h+tv$ for $t>0$ is the sign of its evaluation on $v$. This gives the radial cone. For a differentiable path with both signs of $t$, divide the active row values by $t$ and let $t$ tend to zero from both sides to obtain $A_Iv=0$. The affine path realizes every such $v$. For the quadratic path the active row values are exactly $t^2 A_Iw/2$, proving the stated criterion. Full dimension persists since a compact convex set has nonempty interior precisely when its minimum width on the unit sphere is positive, and ray perturbations on a fixed finite fan give uniform support perturbations there.

For the last assertion take $[-1,1]^2$ and the fan obtained by adding the ray $(1,1)$ to the four cardinal rays. Intersect with $x_1+x_2\le2-t^2$. For small nonzero $t$ the diagonal facet joins $(1,1-t^2)$ to $(1-t^2,1)$. The four cardinal support values remain one, the diagonal value is $2-t^2$, and the function is linear on the cones of the specified fan. The path is two-sided and all first velocities vanish. If the offset instead is $2-t$, the actual diagonal value is $\min(2,2-t)$ near zero, which has unequal one-sided derivatives.
