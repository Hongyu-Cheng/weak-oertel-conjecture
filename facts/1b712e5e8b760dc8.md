## Statement

Let $d\ge1$ and let $v_1,\ldots,v_{d+1}$ span $\mathbb R^d$ and sum to zero. Set $T=\{x:v_i\cdot x\le1\ \forall i\}$ and $V=|T|$. Let $A,K$ be full-dimensional convex bodies. For every full-dimensional convex $B\subseteq T$ with $(A+B)/2\subseteq K$, set $\alpha_i=h_A(-v_i)$, $t_i=h_K(-v_i)$ and $c_i=(1+2t_i-\alpha_i)/(d+1)$. Then
$
B\subseteq E=T\cap\{x:v_i\cdot x\ge\alpha_i-2t_i\ \forall i\}.
$
If some $c_i\le0$, $E$ has zero $d$-volume. Otherwise its exact relative volume is
$
\frac{|E|}{V}=\sum_{J\subseteq\{1,\ldots,d+1\}}(-1)^{|J|}\Bigl(1-\sum_{j\in J}c_j\Bigr)_+^d.
$
If $K=\{x:v_i\cdot x\ge-t_i\ \forall i\}$, then $E=T\cap\{x:x+A\subseteq2K\}$. Whenever this $E$ has positive volume it attains the maximum possible $|B|$ with those $A,K$ and $B\subseteq T$.

## Proof

Taking supports in directions $-v_i$ in the midpoint inclusion gives $\alpha_i+h_B(-v_i)\le2t_i$, which is exactly the claimed lower coordinate bound on $B$. The affine map $x\mapsto((1-v_i\cdot x)/(d+1))_i$ identifies $T$ with the barycentric simplex, by the spanning and balance assumptions. The new lower support bounds are the upper bounds $\lambda_i\le c_i$ on these coordinates. Nonpositive $c_i$ force emptiness or confinement to a coordinate face. If all are positive, the common violation $\lambda_j>c_j$ for $j\in J$ cuts out, after subtracting $c_j$ in the selected coordinates, a simplex of linear scale $1-\sum_{j\in J}c_j$ when this is positive. Otherwise the violation set has zero volume. All coordinate boundaries are volume-null, so inclusion-exclusion gives the exact formula, including $c_i\ge1$.

If the displayed inequalities define $K$, then $x+A\subseteq2K$ is equivalent to requiring $\min_{a\in A}v_i\cdot(x+a)\ge-2t_i$ for every $i$, which is precisely the enclosure inequality. Taking $B=E$ when it is full-dimensional is then admissible and attains the enclosure volume.
