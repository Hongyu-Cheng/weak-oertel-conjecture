## Statement

Let \(n,d\in\mathbb Z_{>0}\), let \(P\subseteq\mathbb R^n\) be a nonempty compact convex set, and let \(g:P\to[0,\infty)\) be concave. Set \(D=P\cap\mathbb Z^n\) and \(W=\sum_{z\in D}g(z)^d\), and suppose \(W>0\). For \(s>0\), set \(N(s)=\#\{z\in D:g(z)\ge s\}\). Then the maximum \(M=\max_{s>0}s^dN(s)\) is finite and attained, and
\[
M\ge 2^{-n-1}W.
\]

## Proof

Compactness of \(P\) implies that \(D\) is finite. Since \(W>0\), the finite set
\[
V:=\{g(z):z\in D,\ g(z)>0\}
\]
is nonempty. If \(N(s)>0\), let \(v\) be the least member of \(V\) satisfying \(v\ge s\). There is no value of \(g\) on \(D\) in \([s,v)\), so \(N(v)=N(s)\), and hence \(v^dN(v)\ge s^dN(s)\). If \(N(s)=0\), then \(s^dN(s)=0\). It follows that
\[
M=\max_{v\in V}v^dN(v),
\]
which proves finiteness and attainment at a positive lattice value. In particular, the use of equality in the definition of \(N\) is preserved at every candidate maximizing level.

Partition \(D\) into its \(2^n\) coordinatewise parity classes. For a parity class \(\epsilon\in(\mathbb Z/2\mathbb Z)^n\), write
\[
D_\epsilon:=\{z\in D:z\equiv\epsilon\pmod 2\},
\qquad
W_\epsilon:=\sum_{z\in D_\epsilon}g(z)^d.
\]
Empty classes and classes containing only zero values have \(W_\epsilon=0\). Since \(\sum_\epsilon W_\epsilon=W>0\), some class \(\epsilon\) satisfies
\[
W_\epsilon\ge 2^{-n}W>0.
\]
Fix such a class. Finiteness gives a point \(z_0\in D_\epsilon\) at which
\[
h:=\max_{z\in D_\epsilon}g(z)=g(z_0)>0.
\]

For each \(z\in D_\epsilon\), define
\[
\phi(z):=\frac{z+z_0}{2}.
\]
Because \(z\) and \(z_0\) have the same coordinatewise parity, \(\phi(z)\in\mathbb Z^n\). Convexity of \(P\) gives \(\phi(z)\in P\), so \(\phi(z)\in D\). The map is injective, since \(\phi(z)=\phi(z')\) implies \(z+z_0=z'+z_0\), hence \(z=z'\). Finally, concavity gives
\[
g(\phi(z))\ge\frac{g(z)+g(z_0)}2=\frac{g(z)+h}{2}.
\]

For \(0<t\le h\), let
\[
A(t):=\#\{z\in D_\epsilon:g(z)\ge t\}.
\]
The preceding integer-valued, injective midpoint map sends this set into the global superlevel set at height \((h+t)/2\). The inequalities are non-strict, so points satisfying \(g(z)=t\) are included on both sides. Thus
\[
A(t)\le N\!\left(\frac{h+t}{2}\right).
\]
By the definition of \(M\),
\[
A(t)\le M\left(\frac{2}{h+t}\right)^d
\qquad(0<t\le h).
\]

The finite layer-cake identity, including its endpoints, is
\[
\begin{aligned}
W_\epsilon
&=\sum_{z\in D_\epsilon}\int_0^{g(z)}d\,t^{d-1}\,dt\\
&=\int_0^h d\,t^{d-1}A(t)\,dt.
\end{aligned}
\]
Indeed, a zero value contributes an integral over a degenerate interval and hence contributes zero; whether the indicator includes \(t=0\) or \(t=g(z)\) changes only measure-zero endpoints. The displayed non-strict superlevel convention is therefore consistent with this identity. Applying the bound for \(A(t)\), then setting \(x=t/h\), gives
\[
W_\epsilon
\le M d2^d\int_0^1\frac{x^{d-1}}{(1+x)^d}\,dx.
\]
For the change of variables \(u=2x/(1+x)\), one has \(x=u/(2-u)\), \(dx=2(2-u)^{-2}du\), and both endpoints \(0,1\) map to \(0,1\). Consequently,
\[
d2^d\int_0^1\frac{x^{d-1}}{(1+x)^d}\,dx
=2d\int_0^1\frac{u^{d-1}}{2-u}\,du
\le 2d\int_0^1u^{d-1}\,du
=2,
\]
where \(2-u\ge1\) on \([0,1]\). Hence \(W_\epsilon\le2M\). Combining this with \(W_\epsilon\ge2^{-n}W\) yields
\[
M\ge\frac{W_\epsilon}{2}\ge2^{-n-1}W,
\]
with the asserted constant exactly.
