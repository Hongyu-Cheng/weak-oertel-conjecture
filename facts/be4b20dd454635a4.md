## Statement

Let \(n,d\ge1\) be integers, and let \(C\subset\mathbb R^n\times\mathbb R^d\) be a convex body invariant under each reflection \(x_i\mapsto1-x_i\), with all other coordinates fixed. Assume \(x_i\in[-1,2]\) at every point of \(C\) for \(2\le i\le n\). There is no further restriction on \(x_1\). When \(n=1\), the coordinate bounds are vacuous.

Use exactly the fiber, mass, and density notation of accepted fact d4a3be98ad8645b7:
\[
\begin{gathered}
\Lambda=\mathbb Z^n\times\mathbb R^d,\qquad S=C\cap\Lambda,\qquad
C_I=\{\mathbf y\in\mathbb R^d:(I,\mathbf y)\in C\},\\
W=\mathcal H_d(S)=\sum_{I\in\mathbb Z^n}|C_I|,\qquad
N_C(\mathbf y)=\sum_{I\in\mathbb Z^n}\mathbf1_{C_I}(\mathbf y),\qquad
R_C(\mathbf y)=\sum_{I\in\mathbb Z^n}\mathbf1_{C_I\cap C_{-I}}(\mathbf y),\\
T=C_{\mathbf0},\qquad
\tau_{R_C}(\mathbf y)
=\inf_{\substack{L\subset\mathbb R^d\ \text{a proper closed halfspace}\\
                  \mathbf y\in L}}\int_LR_C(\mathbf z)\,d\mathbf z .
\end{gathered}
\]
Here \(|C_I|\) is \(d\)-dimensional Lebesgue volume. Assume \(S\ne\varnothing\), and retain the locked actual depth \(h_S(p)=\inf_{H\ni p}\mathcal H_d(S\cap H)\), with every containing closed ambient halfspace allowed.

Put \(\kappa=(\sqrt[3]3-\sqrt[3]2)^{3/2}\). If \(W>0\), then \(T\) is a convex body and there is a single point \(\mathbf y^\star\in T\) such that
\[
\tau_{R_C}(\mathbf y^\star)
\ge\frac{\kappa}{\sqrt2}\frac{W}{2^n},
\qquad
h_S((\mathbf0,\mathbf y^\star))
\ge\frac{\kappa}{2\sqrt2}\frac{W}{2^n}
>\frac{W}{40\,2^n}.
\]
The point is selected before the containing halfspaces. If \(W=0\), there is still a point \(\mathbf y^\star\in T\), and \(h_S((\mathbf0,\mathbf y^\star))\ge W/(40\,2^n)=0\). All assertions include \(n=1\) and closed fiber boundaries.

## Proof

Compactness of \(C\) implies that only finitely many integer sites have nonempty fibers. Every integer fiber is contained in \(T\). Indeed, if the integer value of one coordinate is \(r\), its reflection has value \(1-r\). The closed interval joining these values contains zero because \(r\in\mathbb Z\). Convexity therefore permits replacing that coordinate by zero while preserving every other coordinate. Apply this successively to all \(n\) integer coordinates. In particular, \(T\ne\varnothing\) when \(S\ne\varnothing\). If \(W=0\), choosing any point of \(T\) proves the asserted zero bound. Henceforth assume \(W>0\). Some integer fiber has positive \(d\)-volume, so its containment in the compact convex set \(T\) implies that \(T\) is a convex body.

Write \([2,n]=\{2,\ldots,n\}\), with \([2,1]=\varnothing\). For \(J\subseteq[2,n]\), let \(\mathbf u_J\in\{0,1\}^n\) have entry one exactly on \(J\), using the same indicator-vector convention as d4a3be98ad8645b7. Let \(\mathbf e_1\) be the first integer-coordinate unit vector. Thus \(-k\mathbf e_1-\mathbf u_J\) has first coordinate \(-k\) and has value \(-1\) exactly on \(J\) among the other coordinates. In dimension \(n=1\), this vector is simply \((-k)\). For \(k\ge0\), define
\[
\mathcal E_{k,\mathbf y}
=\{J\subseteq[2,n]:\mathbf y\in C_{-k\mathbf e_1-\mathbf u_J}\},
\qquad
a_k(\mathbf y)=|\mathcal E_{k,\mathbf y}|,
\qquad
A(\mathbf y)=\sum_{k\ge0}a_k(\mathbf y).
\tag{1}
\]
These are new families on \([2,n]\), indexed by the first-coordinate level; they are not the single family on \([n]\) used in the four-level proof of d4a3be98ad8645b7. The sum in (1) has only finitely many possibly nonzero terms, uniformly in \(\mathbf y\), because \(C\) is bounded.

Each \(\mathcal E_{k,\mathbf y}\) is downward closed. If \(i\in J\) and \(J\in\mathcal E_{k,\mathbf y}\), reflect coordinate \(i\) from \(-1\) to \(2\). The segment to the reflected point contains the point with that coordinate zero. Hence \(J\setminus\{i\}\in\mathcal E_{k,\mathbf y}\). Repeating removes any desired subset. The families are also nested:
\(\mathcal E_{k,\mathbf y}\subseteq\mathcal E_{k-1,\mathbf y}\) for \(k\ge1\). To see this, reflect first coordinate \(-k\) to \(k+1\); the intervening segment contains the value \(-(k-1)\), with all other coordinates fixed.

Every integer \(r\) belongs to exactly one reflection orbit \(\{-k,k+1\}\), \(k\ge0\). For each coordinate \(i\ge2\), the only possible integer values are \(-1,0,1,2\), with reflection orbits \(\{-1,2\}\) and \(\{0,1\}\). Thus each pair \((k,J)\) in (1) represents exactly \(2^n\) distinct integer sites: two first-coordinate choices, two choices at each coordinate of \(J\), and two at each remaining coordinate. These sites have exactly the same fiber, by reflection invariance. The orbits partition all possible integer sites, so the original census and mass are
\[
N_C(\mathbf y)=2^nA(\mathbf y),
\qquad
\int_TA(\mathbf y)\,d\mathbf y=\frac{W}{2^n}.
\tag{2}
\]
Every term vanishes outside \(T\), by the fiber containment already proved. On \(T\), the empty subset belongs to \(\mathcal E_{0,\mathbf y}\), so \(A\ge1\).

For two families \(\mathcal E,\mathcal F\) on the same ground set, define
\(D(\mathcal E,\mathcal F)=|\{(J,K)\in\mathcal E\times\mathcal F:J\cap K=\varnothing\}|\).
We next prove the exact reflected census
\[
R_C(\mathbf y)
=D(\mathcal E_{0,\mathbf y},\mathcal E_{0,\mathbf y})
 +2\sum_{k\ge1}
 D(\mathcal E_{k-1,\mathbf y},\mathcal E_{k,\mathbf y}).
\tag{3}
\]
If a site \(I\) contributes to \(R_C(\mathbf y)\), then \(I_i\in\{-1,0,1\}\) for every \(i\ge2\), since both \(I_i\) and \(-I_i\) must lie in \([-1,2]\). Put
\(P=\{i\ge2:I_i=1\}\) and \(M=\{i\ge2:I_i=-1\}\); they are disjoint. Conversely, any ordered disjoint pair \((M,P)\) specifies those \(n-1\) coordinates uniquely.

When \(I_1=0\), membership of \(\mathbf y\) in \(C_I\cap C_{-I}\) is equivalent, by reflections of coordinates with value \(1\), to
\(M,P\in\mathcal E_{0,\mathbf y}\). This yields the first term of (3). When \(I_1=k\ge1\), reflecting that coordinate sends it to \(-(k-1)\), whereas \((-I)_1=-k\). The two membership conditions are exactly
\(M\in\mathcal E_{k-1,\mathbf y}\) and \(P\in\mathcal E_{k,\mathbf y}\). When \(I_1=-k\le-1\), they are exactly
\(M\in\mathcal E_{k,\mathbf y}\) and \(P\in\mathcal E_{k-1,\mathbf y}\). Exchanging the ordered pair shows that the two counts agree. These are all integer values of \(I_1\), proving (3). Every argument is an exact closed-set membership equivalence.

We use the Boolean downset bound established in accepted fact d4a3be98ad8645b7:
\(D(\mathcal E,\mathcal E)\ge|\mathcal E|^{3/2}\).
For completeness, it also holds on an empty ground set. Its elementary proof begins with
\(\sum_{J\in\mathcal E}2^{-|J|}\ge\sqrt{|\mathcal E|}\).
Induct on the size of the ground set, with the empty ground set immediate, whether \(\mathcal E\) is empty or consists of the empty subset. For the inductive step, split according to the presence of the last element. The resulting downward-closed families have cardinalities \(b_0\ge b_1\), and induction bounds the sum below by \(\sqrt{b_0}+\frac12\sqrt{b_1}\). This is at least \(\sqrt{b_0+b_1}\), since the difference of their squares is
\(\sqrt{b_0b_1}-\frac34b_1\ge\frac14b_1\).
For fixed \(J\in\mathcal E\), the map \(K\mapsto K\setminus J\) takes \(\mathcal E\) to members disjoint from \(J\) and has at most \(2^{|J|}\) preimages per image. There are at least \(|\mathcal E|2^{-|J|}\) such members. Summing over \(J\) proves the stated disjoint-pair bound, also for the empty family.

Nestedness implies
\(D(\mathcal E_{k-1,\mathbf y},\mathcal E_{k,\mathbf y})
\ge D(\mathcal E_{k,\mathbf y},\mathcal E_{k,\mathbf y})\).
Consequently (3) gives
\[
R_C(\mathbf y)
\ge a_0(\mathbf y)^{3/2}
 +2\sum_{k\ge1}a_k(\mathbf y)^{3/2}
\ge\sum_{k\ge0}a_k(\mathbf y)^{3/2}.
\tag{4}
\]

We now construct a concave height that measures the number of nonempty levels without depending on the maximum width of \(C\). For \(\mathbf y\in T\), let
\[
\ell(\mathbf y)
=\max\{t\ge0:(-t,0,\ldots,0,\mathbf y)\in C\},
\qquad
q(\mathbf y)=1+\ell(\mathbf y),
\qquad
\nu(\mathbf y)=1+\lfloor\ell(\mathbf y)\rfloor .
\tag{5}
\]
The maximum exists: the set in (5) is nonempty, closed, and bounded, containing zero. Its members form exactly \([0,\ell(\mathbf y)]\), by convexity. Downward closure of \(\mathcal E_{k,\mathbf y}\) implies that it is nonempty if and only if it contains the empty subset, which is equivalent to \(k\le\ell(\mathbf y)\). Thus \(\nu(\mathbf y)\) is the number of nonempty levels, which are exactly \(0,\ldots,\nu(\mathbf y)-1\), including the final level when \(\ell(\mathbf y)\) is an integer. Each such level has at least one member.

The function \(\ell\) is finite, uniformly bounded, concave, and upper semicontinuous on \(T\). Concavity follows by taking convex combinations of the two maximizing points in (5). For upper semicontinuity, if \(\mathbf y_j\to\mathbf y\) in \(T\), take a subsequence of the bounded numbers \(\ell(\mathbf y_j)\) converging to their limit superior. Closedness of \(C\) puts the limiting maximizing point in \(C\), so that limit superior is at most \(\ell(\mathbf y)\). These properties pass to \(q\), which is also at least one. The exact level description gives
\[
\nu(\mathbf y)
\le q(\mathbf y)
\le \nu(\mathbf y)+1
\le2\nu(\mathbf y)
\le2A(\mathbf y).
\tag{6}
\]

For each \(\mathbf y\in T\), Hölder's inequality on the \(\nu(\mathbf y)\) nonempty levels yields
\[
\begin{aligned}
A(\mathbf y)
&\le
\left(\sum_{k=0}^{\nu(\mathbf y)-1}a_k(\mathbf y)^{3/2}\right)^{2/3}
\nu(\mathbf y)^{1/3}\\
&\le R_C(\mathbf y)^{2/3}q(\mathbf y)^{1/3}.
\end{aligned}
\tag{7}
\]
This uses (4) and the lower bound in (6). In particular it applies when only level zero is nonempty, so that \(\nu(\mathbf y)=1\).

Form the lifted set
\(T'=\{(\mathbf y,t)\in\mathbb R^{d+1}:\mathbf y\in T,\ 0\le t\le q(\mathbf y)\}\).
Concavity of \(q\) makes \(T'\) convex. Upper semicontinuity, boundedness, and compactness of \(T\) make it compact. It contains \(T\times[0,1]\), so it has nonempty interior in dimension \(d+1\). Therefore \(T'\) is a convex body. Its \((d+1)\)-dimensional volume is
\[
Q:=|T'|=\int_Tq(\mathbf y)\,d\mathbf y,
\qquad
0<Q\le2\int_TA(\mathbf y)\,d\mathbf y=\frac{2W}{2^n}.
\tag{8}
\]

Define a density on \(\mathbb R^{d+1}\) by
\[
\rho'(\mathbf y,t)=
\begin{cases}
R_C(\mathbf y)/q(\mathbf y),&(\mathbf y,t)\in T',\\
0,&(\mathbf y,t)\notin T'.
\end{cases}
\tag{9}
\]
All original densities are finite sums of indicators of compact sets. The function \(q\) is measurable and at least one on \(T\), and \(T'\) is compact. Thus (9) is a nonnegative measurable integrable function supported on \(T'\). Fubini's theorem gives
\[
\int_{\mathbb R^{d+1}}\rho'
=\int_T R_C,
\qquad
\int_{T'}(\rho')^{2/3}
=\int_T R_C(\mathbf y)^{2/3}q(\mathbf y)^{1/3}\,d\mathbf y
\ge\frac{W}{2^n},
\tag{10}
\]
where the last inequality uses (7) and (2).

Apply the two-thirds density theorem in accepted fact d4a3be98ad8645b7. The exact alias map for this use is: its continuous dimension \(d\) is replaced by \(d+1\), its support body \(T\) by \(T'\), and its density \(\rho\) by \(\rho'\). The original continuous dimension in the fibers \(C_I\), in \(W\), and in \(R_C\) remains \(d\). Writing \(\tau_{\rho'}\) for halfspace depth of this lifted density in \(\mathbb R^{d+1}\), that theorem supplies \((\mathbf y^\star,t^\star)\in T'\) with
\[
\begin{aligned}
\tau_{\rho'}(\mathbf y^\star,t^\star)
&\ge\kappa
 \frac{\left(\int_{T'}(\rho')^{2/3}\right)^{3/2}}{|T'|^{1/2}}\\
&\ge\kappa\frac{(W/2^n)^{3/2}}{\sqrt Q}
\ge\frac{\kappa}{\sqrt2}\frac{W}{2^n}.
\end{aligned}
\tag{11}
\]
All hypotheses of the accepted density theorem were checked above, including compact convex support with nonempty interior in the lifted dimension.

The point \(\mathbf y^\star\) belongs to \(T\). For every proper closed halfspace \(L\subset\mathbb R^d\) containing it, the set \(L\times\mathbb R\) is a proper closed halfspace in \(\mathbb R^{d+1}\) containing \((\mathbf y^\star,t^\star)\). By (9) and Fubini,
\(\int_{L\times\mathbb R}\rho'=\int_L R_C\).
Each such integral is therefore at least (11). Taking the infimum over these \(L\) proves
\[
\tau_{R_C}(\mathbf y^\star)
\ge\tau_{\rho'}(\mathbf y^\star,t^\star)
\ge\frac{\kappa}{\sqrt2}\frac{W}{2^n}.
\tag{12}
\]
This establishes a single continuous point before any original halfspace is chosen.

We verify the passage to actual mixed-integer depth, retaining all halfspaces with zero continuous normal. At each \(\mathbf z\in\mathbb R^d\), the finite set
\(\mathcal P_{\mathbf z}=\{I\in\mathbb Z^n:\mathbf z\in C_I\cap C_{-I}\}\)
has cardinality \(R_C(\mathbf z)\), is invariant under \(I\mapsto-I\), and consists of actual integer sites of \(C\) at \(\mathbf z\). This is the same reflected-pair set used in the actual-depth argument of d4a3be98ad8645b7.

Every proper closed ambient halfspace containing \((\mathbf0,\mathbf y^\star)\) contains its parallel halfspace through that point,
\[
H_0=\{(\mathbf x,\mathbf z):
\mathbf a\cdot\mathbf x+\mathbf b\cdot(\mathbf z-\mathbf y^\star)\le0\},
\qquad
(\mathbf a,\mathbf b)\ne(\mathbf0,\mathbf0).
\tag{13}
\]
Whenever \(\mathbf b\cdot(\mathbf z-\mathbf y^\star)\le0\), at least half the members of \(\mathcal P_{\mathbf z}\) satisfy \(\mathbf a\cdot I\le0\), by pairing \(I\) with \(-I\). The fixed point \(I=\mathbf0\), when present, also satisfies this inequality. All these members lie in \(H_0\). If \(\mathbf b\ne\mathbf0\), integration gives
\[
\mathcal H_d(S\cap H_0)
\ge\frac12\int_{\{\mathbf z:\mathbf b\cdot(\mathbf z-\mathbf y^\star)\le0\}}
 R_C(\mathbf z)\,d\mathbf z
\ge\frac12\tau_{R_C}(\mathbf y^\star).
\tag{14}
\]
If \(\mathbf b=\mathbf0\), the same count holds at every \(\mathbf z\), giving
\(\mathcal H_d(S\cap H_0)\ge\frac12\int R_C\ge\frac12\tau_{R_C}(\mathbf y^\star)\).
A whole-space halfspace, if admitted, also satisfies the bound since \(R_C\le N_C\) pointwise. Every counted boundary point remains included. Infimizing over the original containing halfspaces and using (12) yields
\[
h_S((\mathbf0,\mathbf y^\star))
\ge\frac12\tau_{R_C}(\mathbf y^\star)
\ge\frac{\kappa}{2\sqrt2}\frac{W}{2^n}.
\tag{15}
\]

The numerical comparison is exact. Since \((36/25)^3<3\) and \((63/50)^3>2\), one has \(\sqrt[3]3-\sqrt[3]2>9/50\). Also \((9/50)^3>(3/40)^2\), so \(\kappa>3/40\). Finally \(3>2\sqrt2\), because \(9>8\), whence
\(\kappa/(2\sqrt2)>3/(80\sqrt2)>1/40\).
Together with (15), this gives the stated positive-mass bound.

For \(n=1\), the ground set \([2,n]\) is empty, and each \(\mathcal E_{k,\mathbf y}\) is either empty or consists only of the empty subset. The orbit census, disjoint-pair bound, and every step above already include these cases. In particular no extra integer-dimension hypothesis is used in the lift, which changes only the continuous dimension from \(d\) to \(d+1\). Closedness, the attained maximum in (5), and the non-strict level membership \(k\le\ell(\mathbf y)\) ensure that all formulas include terminal levels and continuous boundaries. This completes the proof.
