## Statement

Let \(n,d\in\mathbb Z_{>0}\), let
\[
\Lambda:=\mathbb Z^n\times\mathbb R^d,
\]
and let \(\mu\) be a finite Borel measure on \(\mathbb R^{n+d}\) such that
\[
\mu(\mathbb R^{n+d}\setminus\Lambda)=0.
\]
If \(\sigma\) is a nonzero log-concave finite Borel measure on
\(\mathbb R^{n+d}\) satisfying \(0\leq\sigma\leq\mu\), then there exists
\(z\in\mathbb Z^n\) such that
\[
\sigma(\{z\}\times\mathbb R^d)=|\sigma|.
\]
This conclusion includes singular measures, point masses, measures supported
on proper affine subspaces, and measures whose supporting integer fiber is not
full-dimensional.

## Proof

Write \(m:=n+d\), and define the support of the possibly singular measure
\(\sigma\) by
\[
K:=\operatorname{supp}\sigma
  :=\{p\in\mathbb R^m:\sigma(B(p,r))>0\text{ for every }r>0\}.
\]
This is an ambient-topological definition and does not require an ambient
Lebesgue density.  Its complement is open.  Moreover,
\(\sigma(\mathbb R^m\setminus K)=0\): if \(p\notin K\), some open ball
containing \(p\) has zero \(\sigma\)-measure; using a countable base of
\(\mathbb R^m\), the whole complement of \(K\) is therefore a countable union
of open sets of zero \(\sigma\)-measure.  Thus \(K\) is a closed set of full
\(\sigma\)-measure.  Since \(\sigma\neq0\), it is nonempty.

The set \(\Lambda\) is closed, because \(\mathbb Z^n\) is closed in
\(\mathbb R^n\).  Measure domination gives
\[
\sigma(\mathbb R^m\setminus\Lambda)
\leq\mu(\mathbb R^m\setminus\Lambda)=0.
\]
For every \(p\notin\Lambda\), the open set
\(\mathbb R^m\setminus\Lambda\) is consequently a zero-\(\sigma\)-measure
neighborhood of \(p\), so \(p\notin K\).  Hence
\[
K\subseteq\Lambda.
\tag{1}
\]
This explicitly uses both setwise domination and closedness of the mixed
lattice; domination only on a smaller test class, such as halfspaces, would
not yield (1).

We next prove that \(K\) is convex, directly from log-concavity and without
assuming that \(\sigma\) is nonsingular.  Let \(a,b\in K\), let
\(0<\theta<1\), and put \(c:=(1-\theta)a+\theta b\).  Given any open
neighborhood \(U\) of \(c\), choose \(r>0\) such that
\(\overline B(c,r)\subseteq U\).  Since \(a,b\in K\),
\[
\sigma(\overline B(a,r))>0
\quad\text{and}\quad
\sigma(\overline B(b,r))>0.
\]
The defining set inequality for a log-concave measure, applied to these two
compact balls, gives
\[
\begin{aligned}
\sigma(\overline B(c,r))
&=\sigma\bigl((1-\theta)\overline B(a,r)
               +\theta\overline B(b,r)\bigr)\\
&\geq
\sigma(\overline B(a,r))^{1-\theta}
\sigma(\overline B(b,r))^\theta
>0.
\end{aligned}
\]
Thus \(\sigma(U)>0\).  Since \(U\) was arbitrary, \(c\in K\), proving that
\(K\) is convex.  The same proof applies when \(K\) lies in a proper affine
subspace, because it uses ambient balls and the measure inequality rather
than a full-dimensional density.

Let \(P:\mathbb R^{n+d}\to\mathbb R^n\) be projection onto the first \(n\)
coordinates.  By nonemptiness and convexity of \(K\), the set \(P(K)\) is a
nonempty convex set.  By (1), \(P(K)\subseteq\mathbb Z^n\).  We claim that
such a convex set contains only one point.  Indeed, if \(u,v\in P(K)\) were
distinct, choose a coordinate \(j\) for which
\(q:=v_j-u_j\in\mathbb Z\setminus\{0\}\), and set
\(\theta:=1/(2|q|)\in(0,1)\).  Convexity would put
\((1-\theta)u+\theta v\) in \(P(K)\), while its \(j\)-th coordinate would be
\[
u_j+\theta q=u_j+\frac{q}{2|q|}\notin\mathbb Z,
\]
contradicting \(P(K)\subseteq\mathbb Z^n\).  Hence \(P(K)=\{z\}\) for some
\(z\in\mathbb Z^n\), and therefore
\[
K\subseteq\{z\}\times\mathbb R^d.
\]
Because \(K\) has full \(\sigma\)-measure, the last inclusion yields
\[
\sigma(\{z\}\times\mathbb R^d)=\sigma(\mathbb R^{n+d})=|\sigma|.
\]
If the affine support is zero-dimensional, then \(K\) is a singleton and the
same argument is precisely the point-mass case.  No step assumes positive
dimension of \(K\), of its affine hull, or of the supporting fiber.
