## Statement

Let $r$ range over an open admissible body parameter domain in $\mathbb R^m$ with positive $C^1$ mass $M(r)$. Suppose $k$ complete $C^1$ raw upper profiles $U_i$ bound all the currently maximizing source neighborhoods, attain $U_i(r_0)=\beta_0M(r_0)$ for the actual normalized maximum $\beta_0$, and all remaining candidates have a strict gap below $\beta_0$ persisting near $r_0$. Set $G_i=U_i-\beta_0 M$. If $DG(r_0)$ has rank $k$, the level set $G=0$ is locally a $C^1$ submanifold of dimension $m-k$ and realizes every vector in $\ker DG(r_0)$ by a $C^1$ tangent curve. Along a sufficiently short part of each curve the actual normalized maximum is at most $\beta_0$. Full rank is impossible at a local minimum in this domain. More generally, if the $k-1$ tie rows $D(U_i-U_1)(r_0)$ for $i>1$ are independent and their common kernel contains $v$ with $D(U_1/M)(r_0)v<0$, an actual local tie curve gives strict normalized depth descent.

## Proof

Full rank allows solving for $k$ coordinates as $C^1$ functions of the others by the implicit function theorem. This parametrization realizes all tangent vectors and gives $U_i/M=\beta_0$ on the constraint manifold, with the persistent gap for the other candidates. Under full rank take a parameter direction with $DG(r_0)v=(-1,\ldots,-1)$. Its sufficiently small positive line segment lies in the open admissible domain and makes all $G_i<0$. Together with the remaining gap this strictly lowers actual depth, excluding full rank at a local minimum. For the last claim instead apply the implicit function theorem to the independent tie rows. The tangent curve with velocity $v$ keeps all $U_i/M$ equal and decreases their common value to first order. If a new source becomes tied later, these statements can only be applied again after adding its profile and checking the enlarged rank, gap and admissibility hypotheses.
