## Statement

Let
\[
K:=\{(x,y)\in\mathbb R^2:\ |5x-y|\leq 5,\ |5x-3y|\leq 5\},
\qquad z_0:=(0,0),
\]
and let \(D:=K\cap\mathbb Z^2\).  Then
\[
D=\{(0,0)\}\mathbin{\cup}
\mathord{\pm}\{(0,1),(1,0),(1,1),(1,2),(1,3),(2,5)\}.
\]
This finite lattice-convex set satisfies \(m_D(z_0)=7\).  For every
\(q\in\{0,1,2\}\), every affinely independent
\(v_0,\ldots,v_q\in D\), and
\(T=\operatorname{conv}\{v_0,\ldots,v_q\}\) containing \(z_0\), one has
\[
\kappa(T,z_0)\leq 2.
\]
Moreover, equality holds for
\(T_0=\operatorname{conv}\{(-1,0),(1,0)\}\).  Consequently
\[
\max_T\frac{\kappa(T,z_0)}{m_D(z_0)}
=\frac27<\frac13,
\]
and no simplex required by the registered statement exists for this
\((K,D,z_0)\).

## Proof

Put \(u=5x-y\) and \(v=5x-3y\).  The linear map
\((x,y)\mapsto(u,v)\) is invertible, with
\[
x=\frac{3u-v}{10},\qquad y=\frac{u-v}{2}.
\]
Thus \(K\) is the inverse image of the square \([-5,5]^2\); in
particular it is a compact full-dimensional parallelogram.  The inverse
formulas give \(|x|\leq2\) and \(|y|\leq5\) throughout \(K\).  Substitution
of the finitely many integer pairs in this bounding rectangle gives
\[
\begin{array}{c|c}
x&\{y:(x,y)\in K\cap\mathbb Z^2\}\\ \hline
-2&\{-5\}\\
-1&\{-3,-2,-1,0\}\\
0&\{-1,0,1\}\\
1&\{0,1,2,3\}\\
2&\{5\},
\end{array}
\]
which is exactly the displayed set \(D\).

The set \(D\setminus\{z_0\}\) consists of six antipodal pairs.  Write any
proper closed halfspace containing \(z_0\) as
\[
Q=\{p\in\mathbb R^2:a\mathbin{\cdot}p\geq b\},
\qquad a\neq0,\quad b\leq0.
\]
For every antipodal pair \(\{p,-p\}\), at least one member has
nonnegative scalar product with \(a\), hence belongs to \(Q\).  Together
with \(z_0\), this proves \(\#(D\cap Q)\geq7\).  Conversely,
\[
Q_0:=\{(x,y):7x+y\geq0\}
\]
contains \(z_0\) and exactly the six displayed positive representatives,
because their scalar products with \((7,1)\) are respectively
\(1,7,8,9,10,19\).  Hence \(m_D(z_0)=7\).

It remains to certify the upper bound for every eligible simplex.  Since
every such \(T\) is contained in \(K\), one has
\(T\cap\mathbb Z^2=T\cap D\).  Rank zero gives only
\(T=\{z_0\}\), for which \(\kappa=1\).  The following finite certificate
enumerates all remaining simplices and uses only integer arithmetic.
For a rank-one simplex it excludes normals that are constant on its
affine line.  Thus every tested set
\(\{p\in\operatorname{aff}(T):n\mathbin{\cdot}p\geq0\}\) is a proper
closed halfspace of \(\operatorname{aff}(T)\) containing \(z_0\).

```python
from collections import Counter
from itertools import combinations

D = ((-2,-5),
     (-1,-3),(-1,-2),(-1,-1),(-1,0),
     (0,-1),(0,0),(0,1),
     (1,0),(1,1),(1,2),(1,3),
     (2,5))
z = (0,0)
N = tuple((r,s) for r in range(-7,8) for s in range(-7,8)
          if (r,s) != (0,0))

assert D == tuple(
    (x,y)
    for x in range(-2,3)
    for y in range(-5,6)
    if abs(5*x-y) <= 5 and abs(5*x-3*y) <= 5
)

def det(a,b,c):
    return ((b[0]-a[0])*(c[1]-a[1])
            -(b[1]-a[1])*(c[0]-a[0]))

def on_segment(p,a,b):
    return (det(a,b,p) == 0
            and (p[0]-a[0])*(p[0]-b[0])
                +(p[1]-a[1])*(p[1]-b[1]) <= 0)

def in_triangle(p,t):
    a,b,c = t
    s = det(a,b,c)
    e = (det(a,b,p),det(b,c,p),det(c,a,p))
    return (s != 0
            and (all(w >= 0 for w in e) if s > 0
                 else all(w <= 0 for w in e)))

def cap_count(P,n):
    return sum(n[0]*p[0]+n[1]*p[1] >= 0 for p in P)

segment_counts = []
for a,b in combinations(D,2):
    if on_segment(z,a,b):
        P = [p for p in D if on_segment(p,a,b)]
        valid = [
            n for n in N
            if n[0]*(b[0]-a[0])+n[1]*(b[1]-a[1]) != 0
        ]
        segment_counts.append(min(cap_count(P,n) for n in valid))

triangle_counts = []
for t in combinations(D,3):
    if in_triangle(z,t):
        P = [p for p in D if in_triangle(p,t)]
        triangle_counts.append(min(cap_count(P,n) for n in N))

assert max(segment_counts) <= 2
assert max(triangle_counts) <= 2
print(len(segment_counts), sorted(Counter(segment_counts).items()))
print(len(triangle_counts), sorted(Counter(triangle_counts).items()))
```

The exact output is

```text
18 [(1, 12), (2, 6)]
160 [(1, 58), (2, 102)]
```

For each of all \(18\) eligible segments and all \(160\) eligible
triangles, the enumerated minimum therefore supplies a particular proper
closed halfspace with at most two lattice points of \(T\).  This proves
\(\kappa(T,z_0)\leq2\) in every rank.

Finally,
\[
T_0\cap\mathbb Z^2=\{(-1,0),(0,0),(1,0)\}.
\]
Every proper closed halfspace of the line
\(\operatorname{aff}(T_0)\) that contains \((0,0)\) contains \((0,0)\)
and at least one endpoint, while either closed halfline based at
\((0,0)\) contains exactly two of these points.  Hence
\(\kappa(T_0,z_0)=2\).  The maximum over all eligible simplices is
therefore exactly \(2\), and \(2<7/3\) completes the counterexample.
