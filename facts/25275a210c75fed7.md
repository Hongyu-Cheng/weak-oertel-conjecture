## Statement

In the affine space $\sum_{i=0}^3 k_i=1$ put $L_0=\lbrace e_0\rbrace$, $L_{\ell+1}=\lbrace2k-e_c:k\in L_\ell,\ c\in\lbrace1,2,3\rbrace\rbrace$, and $S=\lbrace e_1,e_2,e_3\rbrace\cup\bigcup_{\ell=0}^3L_\ell$. Its 43 distinct nodes obey the four-root coefficient, termination and root-maximality conditions with the positive linear radius $r(k)=\sum_i k_i=1$. Thus all positive powers of the radius give unit weights. Each node admits a closed containing halfspace of mass at most $7<43/4$. Each designated root is also the unique minimum Euclidean-norm point of its color in coefficient space. The affine projection of $e_0,e_1,e_2,e_3$ onto $(0,0),(1,0),(0,1),(1,1)$ omits the integer point $(-2,-2)$ in the projected convex hull.

## Proof

Each generation consists of the words $2^\ell e_0-\sum_{b=0}^{\ell-1}2^b e_{c_b}$ with $c_b\in\lbrace1,2,3\rbrace$. The binary digits recover the word, so the four generation sizes are $1,3,9,27$ and different generations have different zeroth coordinate. The odd coordinate is $c_0$ for nonroots and the prescribed parent deletes the lowest digit, reaching $e_0$. The four roots have their own unit parities. This gives all coefficient conditions by terminating-forest-exclusive-binary-root-coefficients. The radius is exactly one at every node, so the designated root is a radius maximum in each color; every nonroot has squared coefficient norm greater than one, while the only unit vector of each color is its root.

Write $k'=(k_1,k_2,k_3)$ and take the closed cap $u\cdot l'\ge u\cdot k'$ at each representative $k$. The parts column counts the three external roots together, then generations zero through three, respectively.

To check each entry put $b=u\cdot k'$. Count the coordinates $u_i\ge b$ for the external roots, count $0\ge b$ for $L_0$, and for each $\ell=1,2,3$ count the words satisfying $-\sum_{h=0}^{\ell-1}2^h u_{c_h}\ge b$. This includes equality and verifies the table by integer comparisons. The sorted allocations of the binary digits of $1,3,7$ have respectively $1,2,5$ possible types, which are the listed nonroot rows. Together with the two root types this exhausts the set modulo permutations of $1,2,3$. Apply the same permutation to each normal to obtain the corresponding cap. This proves the upper bound on maximum depth, without requiring that seven be the exact maximum.

In the square projection a word maps to $(-m_1-m_3,-m_2-m_3)$ where $m_i$ are the nonnegative digit allocations. To obtain $(-2,-2)$ requires $m_1=m_2=2-m_3$. If $m_3<2$ this repeats a binary digit, which is impossible. If $m_3=2$, the other two allocations are zero and the total allocation is two, whereas the possible totals are $0,1,3,7$. No external root projects there. But $(-2,-2)$ is the combination of $(0,0),(-7,0),(0,-7)$ with weights $3/7,2/7,2/7$, so it lies in the hull.
