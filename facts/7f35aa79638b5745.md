## Statement

For every integer \(j\ge0\), there is a symmetric joint probability mass function \(K_j\) on \(\{0,\ldots,j\}^2\) whose two marginals are the same probability mass function \(q_j\), and such that
\[
\frac{1}{2(j+1)}\le q_j(x)\le\frac{2}{j+1},\qquad
K_j(x,y)\ge\frac18 q_j(x)q_j(y)
\quad(0\le x,y\le j).
\]
If \((X,Y)\) has joint law \(K_j\), then \(\mathbb P(X-Y=k)=1/(2j+1)\) for every integer \(-j\le k\le j\).

## Proof

Fix \(j\ge0\), put \(m=j+1\), and for each integer \(-j\le k\le j\) define
\[
r_k=\frac{1}{2j+1}-\frac{m-|k|}{2m^2}.
\]
These numbers are symmetric in \(k\) and nonnegative, because
\(r_k\ge1/(2m-1)-1/(2m)=1/[2m(2m-1)]>0\).

Start with \(R_j(x,y)=0\) at every pair \((x,y)\in\{0,\ldots,j\}^2\). For each \(k\), distribute mass \(r_k\) as follows. If \(j+k\) is even, add all of \(r_k\) at
\[
\left(\frac{j+k}{2},\frac{j-k}{2}\right).
\]
If \(j+k\) is odd, add mass \(r_k/2\) at each of
\[
\left(\frac{j+k-1}{2},\frac{j-k-1}{2}\right),\qquad
\left(\frac{j+k+1}{2},\frac{j-k+1}{2}\right).
\]
In the even case both coordinates are integers between 0 and \(j\). In the odd case, \(-j+1\le k\le j-1\), so both displayed pairs also have integer coordinates between 0 and \(j\). Every pair receiving mass for \(k\) has coordinate difference \(k\). Swapping coordinates sends the placement for \(k\) to the placement for \(-k\), with the same weights, so \(R_j(x,y)=R_j(y,x)\).

Define \(K_j(x,y)=1/(2m^2)+R_j(x,y)\). There are exactly \(m-|k|\) pairs with coordinate difference \(k\). Consequently,
\[
\sum_{x-y=k}K_j(x,y)
=\frac{m-|k|}{2m^2}+r_k
=\frac{1}{2j+1}.
\]
The \(2j+1\) possible differences partition the square, so \(K_j\) has total mass 1. It is nonnegative and symmetric. Thus \(q_j(x):=\sum_{y=0}^jK_j(x,y)\) is a probability mass function, and symmetry makes it both the first and the second marginal. The preceding identity gives the asserted difference law.

The constant component contributes \(1/(2m)\) to every row, proving the lower bound on \(q_j\). For a fixed row \(x\), the even placement can contribute only for \(k=2x-j\), and the two odd placements can contribute only for \(k=2x-j+1\) and \(k=2x-j-1\), respectively. The first contribution has weight \(r_k\) and each of the other two has weight \(r_k/2\); terms with \(k\notin[-j,j]\) contribute nothing. Since \(r_k\le1/(2j+1)=1/(2m-1)\), every residual row has mass at most \(2/(2m-1)\). For \(j\ge1\), hence \(m\ge2\), this gives
\[
q_j(x)\le\frac{1}{2m}+\frac{2}{2m-1}\le\frac{2}{m},
\]
where the last inequality is equivalent to \(2m\ge3\). When \(j=0\), the construction gives \(K_0(0,0)=q_0(0)=1\), which satisfies both marginal bounds as well.

Finally, for every \(j\ge0\) and every \(x,y\in\{0,\ldots,j\}\), the established upper bound on the marginal gives
\[
\frac18 q_j(x)q_j(y)\le\frac{1}{2m^2}\le K_j(x,y).
\]
This proves the claimed minorization with the absolute constant \(\beta=1/8\).
