## Statement

Let \(n,d\in\mathbb Z_{>0}\), let \(C\subseteq\mathbb R^{n+d}\) be a convex body, and put
\[
C_z:=\{x\in\mathbb R^d:(z,x)\in C\},\qquad
w_z:=\operatorname{vol}_d(C_z),\qquad
W:=\sum_{z\in\mathbb Z^n}w_z.
\]
Assume \(W>0\). Let \(z_0\in\mathbb Z^n\) satisfy \(w_{z_0}>0\) and
\[
\sum_{z\in Q\cap\mathbb Z^n}w_z\ge 2^{-n}W
\]
for every proper closed halfspace \(Q\subseteq\mathbb R^n\) containing \(z_0\). Set \(S:=C\cap(\mathbb Z^n\times\mathbb R^d)\). Let \(y_0\in\operatorname{int}C_{z_0}\) and
\[
t:=h_S((z_0,y_0))=\max_{y\in C_{z_0}}h_S((z_0,y)).
\]
Fix \(\varepsilon>0\), and take the family supplied by accepted fact `981a6c3aa5982216`: positive weights \(\lambda_1,\ldots,\lambda_r\) with \(\sum_i\lambda_i=1\), vectors \(a_i\in\mathbb R^n\), \(b_i\in\mathbb R^d\) with \(\sum_i\lambda_i b_i=0\), and closed halfspaces
\[
H_i:=\{(z,x):a_i^\top(z-z_0)+b_i^\top(x-y_0)\ge0\}
\]
such that
\[
\mathcal H_d(S\cap H_i)\le t+\varepsilon
\qquad(1\le i\le r).
\]
Define
\[
A_i:=C\cap H_i,\qquad
f_i(z):=\operatorname{vol}_d((A_i)_z)\quad(z\in\mathbb R^n),
\]
and
\[
\Psi_\varepsilon(z):=
\begin{cases}
\prod_{i=1}^r f_i(z)^{\lambda_i},&f_i(z)>0\text{ for every }i,\\
0,&f_i(z)=0\text{ for some }i.
\end{cases}
\]
Then every zero-extended \(f_i:\mathbb R^n\to[0,\infty)\) is globally log-concave, and \(\Psi_\varepsilon\) is globally log-concave:
\[
\Psi_\varepsilon((1-\theta)z+\theta z')
\ge
\Psi_\varepsilon(z)^{1-\theta}\Psi_\varepsilon(z')^\theta
\qquad(z,z'\in\mathbb R^n,\ 0\le\theta\le1).
\]
For
\[
P_i:=\{z\in\mathbb R^n:f_i(z)>0\}
=\{z:(A_i)_z\text{ has nonempty interior in }\mathbb R^d\},
\]
each \(P_i\) is convex, and the exact positive support is
\[
\{z:\Psi_\varepsilon(z)>0\}=\bigcap_{i=1}^rP_i.
\]
Thus, if closed support means the closure of the positive set, then
\[
\operatorname{supp}\Psi_\varepsilon
=\overline{\bigcap_{i=1}^rP_i}.
\]
In particular, projected points carrying only empty or lower-dimensional fibers are not in \(P_i\), so \(P_i\) cannot in general be replaced by \(\operatorname{proj}_{\mathbb R^n}(A_i)\). Moreover, \(z_0\in\bigcap_iP_i\).

For every \(z\in\mathbb R^n\),
\[
0\le\Psi_\varepsilon(z)\le w_z
\quad\text{and}\quad
\Psi_\varepsilon(z)\le\sum_{i=1}^r\lambda_i f_i(z).
\]
All lattice sums below are finite, and
\[
\sum_{z\in\mathbb Z^n}\Psi_\varepsilon(z)
\le
\sum_{i=1}^r\lambda_i\mathcal H_d(S\cap H_i)
\le t+\varepsilon.
\]

Finally, put
\[
\bar a:=\sum_{i=1}^r\lambda_i a_i,\qquad
Q_\varepsilon:=\{z:\bar a^\top(z-z_0)\ge0\},
\]
with \(Q_\varepsilon=\mathbb R^n\) when \(\bar a=0\), and write
\[
W_{Q_\varepsilon}:=\sum_{z\in Q_\varepsilon\cap\mathbb Z^n}w_z.
\]
Then \(W_{Q_\varepsilon}\ge2^{-n}W\). For every \(L_\varepsilon\ge0\), the conditional implication
\[
\sum_{z\in Q_\varepsilon\cap\mathbb Z^n}\Psi_\varepsilon(z)\ge L_\varepsilon
\quad\Longrightarrow\quad
h_S((z_0,y_0))=t\ge L_\varepsilon-\varepsilon
\]
holds. In particular, for any fixed \(\alpha\ge0\),
\[
\sum_{z\in Q_\varepsilon\cap\mathbb Z^n}\Psi_\varepsilon(z)
\ge\alpha W_{Q_\varepsilon}
\quad\Longrightarrow\quad
t\ge\alpha 2^{-n}W-\varepsilon.
\]
Consequently, if such an overlap inequality with the same \(\alpha\) holds for families associated with a sequence \(\varepsilon_k\downarrow0\), then
\[
h_S((z_0,y_0))\ge\alpha 2^{-n}W.
\]
No unconditional positive lower bound for the overlap sum is claimed.

## Proof

Fix \(i\). Convexity of \(A_i\) gives, for \(z,z'\in\mathbb R^n\) and \(0<\theta<1\),
\[
(1-\theta)(A_i)_z+\theta(A_i)_{z'}
\subseteq
(A_i)_{(1-\theta)z+\theta z'}.
\]
If \(f_i(z)>0\) and \(f_i(z')>0\), the \(d\)-dimensional Brunn--Minkowski inequality and the weighted arithmetic-geometric mean inequality give
\[
\begin{aligned}
f_i((1-\theta)z+\theta z')^{1/d}
&\ge
(1-\theta)f_i(z)^{1/d}+\theta f_i(z')^{1/d}\\
&\ge
f_i(z)^{(1-\theta)/d}f_i(z')^{\theta/d}.
\end{aligned}
\]
Raising to the \(d\)-th power proves the log-concavity inequality for \(f_i\) when both endpoint values are positive. If either endpoint value is zero, the right-hand side of the log-concavity inequality is zero, so the inequality is automatic. The cases \(\theta=0,1\) are identities. Hence the zero extension of \(f_i\) is log-concave on all of \(\mathbb R^n\), including across empty and lower-dimensional fibers.

If both \(\Psi_\varepsilon(z)\) and \(\Psi_\varepsilon(z')\) are positive, applying the preceding inequality to every \(i\), raising it to \(\lambda_i\), and multiplying yields
\[
\begin{aligned}
\Psi_\varepsilon((1-\theta)z+\theta z')
&\ge
\prod_i\left(f_i(z)^{1-\theta}f_i(z')^\theta\right)^{\lambda_i}\\
&=\Psi_\varepsilon(z)^{1-\theta}\Psi_\varepsilon(z')^\theta.
\end{aligned}
\]
If either endpoint value of \(\Psi_\varepsilon\) is zero, the desired inequality is again automatic. This proves global log-concavity without taking logarithms at a zero.

Every fiber \((A_i)_z\) is a compact convex subset of \(\mathbb R^d\). Such a set has positive \(d\)-volume if and only if it has nonempty interior in \(\mathbb R^d\). This proves the displayed description of \(P_i\). Its convexity also follows from the positive-endpoint Brunn--Minkowski inequality. Since all \(\lambda_i\) are positive, the defining product is positive exactly when every factor is positive, proving
\[
\{\Psi_\varepsilon>0\}=\bigcap_iP_i
\]
and the asserted closed-support formula. This also shows why a projected lower-dimensional fiber must not be counted in the positive support.

At the anchor fiber,
\[
(A_i)_{z_0}
=C_{z_0}\cap\{x:b_i^\top(x-y_0)\ge0\}.
\]
Because \(y_0\in\operatorname{int}C_{z_0}\), this set contains a half-ball of positive \(d\)-volume when \(b_i\ne0\), and it is all of \(C_{z_0}\) when \(b_i=0\). Thus \(f_i(z_0)>0\) for every \(i\), proving \(z_0\in\bigcap_iP_i\).

Since \(A_i\subseteq C\), one has \(0\le f_i(z)\le w_z\). If \(w_z>0\), taking the weighted product gives \(\Psi_\varepsilon(z)\le w_z^{\sum_i\lambda_i}=w_z\); if \(w_z=0\), every \(f_i(z)=0\), and the same conclusion holds. Weighted arithmetic-geometric mean gives
\[
\Psi_\varepsilon(z)\le\sum_i\lambda_i f_i(z)
\]
for nonnegative \(f_i(z)\), with the stated zero convention.

The base projection of compact \(C\) is bounded, so it contains only finitely many lattice points. Hence all lattice sums in question are finite. By the definition of mixed-integer volume,
\[
\sum_{z\in\mathbb Z^n}f_i(z)=\mathcal H_d(S\cap H_i).
\]
Therefore
\[
\begin{aligned}
\sum_{z\in\mathbb Z^n}\Psi_\varepsilon(z)
&\le
\sum_{z\in\mathbb Z^n}\sum_i\lambda_i f_i(z)\\
&=
\sum_i\lambda_i\mathcal H_d(S\cap H_i)\\
&\le
\sum_i\lambda_i(t+\varepsilon)
=t+\varepsilon.
\end{aligned}
\]

The halfspace \(Q_\varepsilon\) contains \(z_0\). If \(\bar a\ne0\), it is a proper closed halfspace, so the assumed weighted centerpoint property gives \(W_{Q_\varepsilon}\ge2^{-n}W\). If \(\bar a=0\), then \(Q_\varepsilon=\mathbb R^n\) and \(W_{Q_\varepsilon}=W\), so the same bound holds. Finally, any assumed lower bound \(L_\varepsilon\) on the overlap satisfies
\[
L_\varepsilon
\le
\sum_{z\in Q_\varepsilon\cap\mathbb Z^n}\Psi_\varepsilon(z)
\le
\sum_{z\in\mathbb Z^n}\Psi_\varepsilon(z)
\le t+\varepsilon.
\]
Thus \(t\ge L_\varepsilon-\varepsilon\). Taking \(L_\varepsilon=\alpha W_{Q_\varepsilon}\) and using \(W_{Q_\varepsilon}\ge2^{-n}W\) gives
\[
t\ge\alpha2^{-n}W-\varepsilon.
\]
Because \(t=h_S((z_0,y_0))\) is independent of \(\varepsilon\), passage along any sequence \(\varepsilon_k\downarrow0\) for which the same \(\alpha\)-overlap hypothesis holds proves the final conditional depth bound. No step supplies the overlap hypothesis itself.
