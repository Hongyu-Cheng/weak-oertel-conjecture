## Statement

Let $\pi$ be a martingale coupling from a finite compactly supported measure $\nu$ to $\eta$ in $\mathbb R^m$, and $\Phi$ a finite continuous convex function on $\mathbb R^m$. If $\int\Phi\,d\nu=\int\Phi\,d\eta$, then for $\nu$-almost every $w$, simultaneously for every $a\in\partial\Phi(w)$, the conditional law $\pi_w$ is concentrated on $\{w':\Phi(w')=\Phi(w)+a\cdot(w'-w)\}$. A countable list of equality tests can use the same full-measure source set. If one test is strictly convex the coupling is diagonal. If one is nonnegative with closed convex zero set $D$, its rows from $D$ stay in $D$.

## Proof

The conditional Jensen gap $\int\Phi\,d\pi_w-\Phi(w)$ is nonnegative and has integral zero, hence vanishes on one full-measure set where the martingale barycenter condition also holds. At each such $w$, any supporting affine function with slope $a\in\partial\Phi(w)$ gives a nonnegative gap with conditional integral zero, proving the contact assertion without selecting $a$ measurably. Intersect the source sets for countably many tests. Strict convexity makes each affine contact set a singleton, and a nonnegative test with $\Phi(w)=0$ has $\Phi=0$ almost surely in any zero-gap row from $w$.
