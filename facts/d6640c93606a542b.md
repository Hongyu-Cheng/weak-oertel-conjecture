## Statement

Let \(N\ge1\) be an integer, put \(n=N-1\), and let \(a<b\) be real numbers. Let \(u_1,\ldots,u_n\) be real affine functions that are nonnegative on \([a,b]\) and positive on \((a,b)\). Define

\[
P=\left\{(x,t)\in\mathbb R^n\times\mathbb R:
a\le t\le b,\quad 0\le x_i\le u_i(t)\text{ for }1\le i\le n\right\},
\qquad D=P\cap\mathbb Z^N,
\]

and assume \(D\ne\varnothing\). Here \(n=N-1\) counts the horizontal coordinates, and the height of an original lattice point \(I\in D\) is its last coordinate \(I_N\). For any \(h\in\mathbb R\), assign the original weights \(w_I=e^{-(I_N-h)^2}\) and put \(W=\sum_{I\in D}w_I\).

There exist an integer height \(s^\star\in[a,b]\) and an original point \(J\in D\) with \(J_N=s^\star\) such that every closed halfspace \(H\subseteq\mathbb R^N\) containing \(J\) satisfies

\[
\sum_{\substack{I\in D\cap H\\ I_N=s^\star}}w_I
\ge \frac{W}{400\cdot 2^N}.
\tag{1}
\]

For \(n=0\), the empty product is one and a horizontal product of zero sets is the single empty tuple. Thus the statement includes \(N=1\).

## Proof

Let \(\mathcal T=[a,b]\cap\mathbb Z\). For \(s\in\mathcal T\), set \(m_i(s)=\lfloor u_i(s)\rfloor\). The complete original support in that row is exactly

\[
\{I\in D:I_N=s\}
=\prod_{i=1}^n\{0,1,\ldots,m_i(s)\}\times\{s\},
\qquad
W_s=e^{-(s-h)^2}\prod_{i=1}^n\bigl(m_i(s)+1\bigr).
\tag{2}
\]

Every \(m_i(s)\) is nonnegative. Consequently every integer height in \([a,b]\) is occupied, there are no occupied heights outside this interval, and \(D\ne\varnothing\) implies that \(\mathcal T\) is a nonempty finite interval of integers. Formula (2) includes the point at an integer upper bound and the singleton coordinate set when a width is zero. In particular, it retains all original boundary points, and \(W=\sum_{s\in\mathcal T}W_s\).

For every row, put \(r_i(s)=\lfloor m_i(s)/2\rfloor\) and \(o_i(s)=2r_i(s)+1\). The integer box

\[
C_s=\prod_{i=1}^n\{0,1,\ldots,2r_i(s)\}\times\{s\},
\qquad
J_s=\bigl(r_1(s),\ldots,r_n(s),s\bigr),
\qquad
R_s=e^{-(s-h)^2}\prod_{i=1}^n o_i(s)
\tag{3}
\]

lies in the original row, is centrally symmetric about the original point \(J_s\), and has total original weight \(R_s>0\). A closed halfspace containing \(J_s\) contains at least one point of every pair \(I,2J_s-I\) in \(C_s\). Indeed, if both points were in its open complementary halfspace, so would their midpoint \(J_s\). The fixed point \(J_s\) is also retained. All points in the row have equal weight, so every such halfspace satisfies

\[
\sum_{\substack{I\in D\cap H\\I_N=s}}w_I\ge \frac{R_s}{2}.
\tag{4}
\]

This argument also applies when \(C_s\) is a singleton. We shall prove \(W\le400\cdot2^n\max_{s\in\mathcal T}R_s\).

We first establish an elementary estimate for a positive finite sequence \((f_s)_{s=p}^q\) on consecutive integers. Suppose

\[
\log f_{s+1}-2\log f_s+\log f_{s-1}\le-2
\qquad(p<s<q).
\tag{5}
\]

Choose any sampled maximizer \(s_0\). When the right neighbor exists, \(\log f_{s_0+1}-\log f_{s_0}\le0\). The successive logarithmic increments decrease by at least two by (5). Summing those increments therefore gives
\(f_{s_0+j}\le f_{s_0}e^{-j(j-1)}\) whenever \(j\ge1\) and \(s_0+j\le q\). Apply the same argument to the sequence with its order reversed to obtain \(f_{s_0-j}\le f_{s_0}e^{-j(j-1)}\) for every available left neighbor. Empty sides contribute nothing. Since \(j(j-1)\ge2(j-1)\) for \(j\ge2\), it follows that

\[
\begin{aligned}
\sum_{s=p}^q f_s
&\le f_{s_0}\left(1+2\sum_{j=1}^{\infty}e^{-j(j-1)}\right)\\
&\le f_{s_0}\left(3+2\sum_{j=1}^{\infty}e^{-2j}\right)
=f_{s_0}\left(3+\frac{2}{e^2-1}\right)
<4f_{s_0}.
\end{aligned}
\tag{6}
\]

The last inequality uses \(e^2>3\). For a sequence with just one entry the same conclusion is immediate. Thus (6) requires no information about an unsampled maximizer and allows a sampled maximum at an endpoint or a tie.

For each \(s\in\mathcal T\), define the wide-coordinate set \(A_s=\{i:u_i(s)\ge2\}\). Partition \(\mathcal T\) into its maximal nonempty consecutive integer intervals on which \(A_s\) is constant, and denote this finite family by \(\mathcal B\). For \(B\in\mathcal B\), let \(A_B\) be that fixed set and let \(k_B=|A_B|\). Define, for \(t\in[a,b]\),

\[
F_B(t)=e^{-(t-h)^2}\prod_{i\in A_B}\bigl(u_i(t)+1/2\bigr).
\tag{7}
\]

All factors are strictly positive because the widths are nonnegative. The function \(\log F_B(t)+t^2\) is concave on \([a,b]\): its affine Gaussian contribution is \(2ht-h^2\), and each remaining summand satisfies
\(\frac{d^2}{dt^2}\log(u_i(t)+1/2)=-(u_i')^2/(u_i(t)+1/2)^2\le0\).
For any three consecutive integer heights in \(B\), midpoint concavity, together with the second difference of \(t^2\), therefore yields (5) for \(f_s=F_B(s)\). By (6),
\(\sum_{s\in B}F_B(s)\le4\max_{s\in B}F_B(s)\).

At a narrow coordinate, \(u_i(s)<2\), so \(m_i(s)+1\le2\) and \(o_i(s)=1\). At a wide coordinate, \(u=u_i(s)\ge2\) and \(m=\lfloor u\rfloor\) give

\[
m+1\le u+1\le\frac65\left(u+\frac12\right).
\tag{8}
\]

To compare the latter factor with the odd core, put \(r=\lfloor m/2\rfloor\ge1\). Since \(m\) is either \(2r\) or \(2r+1\), one has \(u<m+1\le2r+2\), and hence

\[
u+\frac12<2r+\frac52\le3r+\frac32
=\frac32(2r+1).
\tag{9}
\]

In particular, \(u_i(s)+1/2\le(3/2)o_i(s)\) at every wide coordinate, including every integer width. Combining (2), (3), and (7)--(9), for \(s\in B\) we obtain

\[
W_s\le2^{n-k_B}\left(\frac65\right)^{k_B}F_B(s),
\qquad
F_B(s)\le\left(\frac32\right)^{k_B}R_s.
\tag{10}
\]

Consequently,

\[
\begin{aligned}
\sum_{s\in B}W_s
&\le4\cdot2^{n-k_B}\left(\frac65\right)^{k_B}
\max_{s\in B}F_B(s)\\
&\le4\cdot2^n\left(\frac9{10}\right)^{k_B}
\max_{s\in B}R_s\\
&\le4\cdot2^n\left(\frac9{10}\right)^{k_B}
\max_{s\in\mathcal T}R_s.
\end{aligned}
\tag{11}
\]

It remains to count the intervals with each value of \(k_B\). For \(0\le k\le n\), let \(b_k\) be the number of intervals \(B\in\mathcal B\) with \(k_B=k\). We claim that \(b_k\le k+1\).

As integer height increases, membership of any positive-slope coordinate in \(A_s\) is nondecreasing; membership of any negative-slope coordinate is nonincreasing; and membership of any zero-slope coordinate is constant. These statements use the threshold \(u_i(s)\ge2\) exactly, with equality included. Moreover, if \(A_s=A_t\) for two heights \(s<t\), each of these monotone coordinate indicators is constant between them, so all the intervening wide-coordinate sets are identical. Thus two distinct maximal intervals in \(\mathcal B\) cannot have the same set \(A_B\).

If \(b_k>0\), choose ordered representatives \(s_1<\cdots<s_{b_k}\) from the intervals of cardinality \(k\). Let \(d_j\) count the negative-slope coordinates in \(A_{s_j}\). The negative-slope subsets are nested decreasing, so \(d_{j+1}\le d_j\). If equality held for some \(j\), those subsets would be identical. The zero-slope subsets are always identical. Since \(|A_{s_j}|=|A_{s_{j+1}}|=k\), the positive-slope subsets would then have equal cardinalities; their nesting in the increasing direction would make them identical as well. This would give \(A_{s_j}=A_{s_{j+1}}\), contradicting distinct maximal intervals. Therefore
\(k\ge d_1>d_2>\cdots>d_{b_k}\ge0\), which proves \(b_k\le k+1\).

This counting argument is made on the actual integer rows. In particular, it allows arbitrarily many coordinate changes between two adjacent integer heights, and it allows an equality row on which increasing coordinates have become wide while decreasing coordinates remain wide.

Summing (11) over the exact partition of \(\mathcal T\), and using the count just proved, gives

\[
\begin{aligned}
W
&\le4\cdot2^n\max_{s\in\mathcal T}R_s
\sum_{k=0}^n b_k\left(\frac9{10}\right)^k\\
&\le4\cdot2^n\max_{s\in\mathcal T}R_s
\sum_{k=0}^{\infty}(k+1)\left(\frac9{10}\right)^k\\
&=400\cdot2^n\max_{s\in\mathcal T}R_s.
\end{aligned}
\tag{12}
\]

The final series equals \((1-9/10)^{-2}=100\), as follows by multiplying two convergent geometric series. All estimates also hold for \(n=0\): there is one wide-coordinate pattern, every product in (2), (3), and (7) is empty, and the interval count has only \(b_0=1\).

Choose \(s^\star\) maximizing \(R_s\) on the nonempty finite set \(\mathcal T\) and set \(J=J_{s^\star}\). For every closed halfspace containing this original point, (4) and (12) imply

\[
\sum_{\substack{I\in D\cap H\\I_N=s^\star}}w_I
\ge\frac{R_{s^\star}}2
\ge\frac{W}{800\cdot2^n}
=\frac{W}{400\cdot2^N},
\]

which is (1). Every quantity in this final inequality uses the original complete support and the original row weights.
