## Statement

Let the complete rooted binary tree of height six have vertices \(1,\ldots,127\), with children \(2v,2v+1\) whenever those labels are at most \(127\). For each \(v=2,\ldots,127\), let \(t_v\in\mathbb R\) be the variable on the edge from the parent of \(v\) to \(v\). Set \(t_1=0\), and set every missing-child variable equal to zero. Put \(s=29/2\), and define

\[
\begin{aligned}
Z_B&=\int_{\mathbb R^{126}}
 \exp\left[-s\left(\sum_{v=2}^{127}|t_v|
       +\sum_{v=1}^{127}|1/2-t_v-t_{2v}-t_{2v+1}|\right)\right]dt,\\
\theta_s(x)&=\sum_{a\in\mathbb Z}e^{-s|a-x|},\\
Z_{\mathrm{all}}&=\int_{\mathbb R^{126}}
 e^{-s\sum_{v=2}^{127}|t_v|}
 \prod_{v=1}^{127}\theta_s(1/2-t_v-t_{2v}-t_{2v+1})\,dt.
\end{aligned}
\]

Both integrals are finite and strictly positive, and \(Z_{\mathrm{all}}/Z_B<(8/5)^{127}\). The executable certificate below uses only Python standard-library exact integers and rational numbers.

## Proof

We first justify finiteness and the discretization, then prove the recurrences and all arithmetic enclosure rules used by the certificate.

The function \(\theta_s\) is one-periodic. If \(0\le x\le1\), summing its two geometric tails gives \(\theta_s(x)=(e^{-sx}+e^{-s(1-x)})/(1-e^{-s})\). Since \((1-e^{-sx})(1-e^{-s(1-x)})\ge0\), its numerator is at most \(1+e^{-s}\). Consequently \(\theta_s\) is bounded above by \((1+e^{-s})/(1-e^{-s})\) on all of \(\mathbb R\). Integrating the edge factors separately gives

\[
0<Z_B\le (2/s)^{126},\qquad
0<Z_{\mathrm{all}}\le
\left(\frac{1+e^{-s}}{1-e^{-s}}\right)^{127}(2/s)^{126}<\infty.
\]

Strict positivity follows by integrating the positive integrands on any cube with positive volume. All sums and integrals below have nonnegative summands, so Tonelli's theorem permits their rearrangement.

Put \(m=126\), \(M=1024\), and \(q=e^{-s/M}\). For \(a\in\mathbb Z^{127}\), define

\[
E_a(t)=\sum_{v=2}^{127}|t_v|
 +\sum_{v=1}^{127}|a_v-1/2+t_v+t_{2v}+t_{2v+1}|.
\]

Thus the integrand defining \(Z_B\) is \(e^{-sE_0(t)}\), while the integrand defining \(Z_{\mathrm{all}}\) is \(\sum_a e^{-sE_a(t)}\). Each edge variable appears in exactly three absolute values: its edge term, the residual at its own vertex, and the residual at its parent. The triangle inequality therefore gives \(|E_a(t)-E_a(u)|\le3\sum_{v=2}^{127}|t_v-u_v|\), uniformly in \(a\).

For \(k\in\mathbb Z^m\), use the half-open centered cell \(C_k=\prod_{v=2}^{127}[(k_v-1/2)/M,(k_v+1/2)/M)\). These cells partition \(\mathbb R^m\), have volume \(M^{-m}\), and satisfy \(\sum_v|t_v-k_v/M|\le m/(2M)\) on each cell. Define the raw grid sums

\[
\begin{aligned}
\mathcal A&=\sum_{k\in\mathbb Z^m}\sum_{a\in\mathbb Z^{127}}
 e^{-sE_a(k/M)},\\
\mathcal F&=\sum_{k\in\{-M,\ldots,M\}^m}e^{-sE_0(k/M)}.
\end{aligned}
\]

The cell comparison gives \(Z_{\mathrm{all}}\le M^{-m}e^{3sm/(2M)}\mathcal A\) and \(Z_B\ge M^{-m}e^{-3sm/(2M)}\mathcal F\). For the second inequality one integrates only over the cells with \(|k_v|\le M\). Those cells remain disjoint even though the outermost ones extend beyond \([-1,1]^m\), which is allowed because the original integral has domain \(\mathbb R^m\). It follows that

\[
\frac{Z_{\mathrm{all}}}{Z_B}
 \le e^{5481/1024}\frac{\mathcal A}{\mathcal F}
 <729\frac{\mathcal A}{\mathcal F}.
\]

Indeed \(3sm/M=5481/1024<6\), and \(e<3\): from \(j!\ge2^{j-1}\) for \(j\ge2\), with a strict inequality when \(j=3\), the exponential series gives \(e=2+\sum_{j=2}^{\infty}1/j!<2+\sum_{j=2}^{\infty}2^{1-j}=3\). Thus \(e^{5481/1024}<e^6<3^6=729\).

For an integer argument \(r\), define the \(M\)-periodic kernel

\[
\Theta_q(r)=\sum_{j\in\mathbb Z}q^{|r+Mj|}
 =\frac{q^r+q^{M-r}}{1-q^M}\quad(0\le r<M).
\]

The displayed identity follows by summing the two geometric tails, including the case \(r=0\). In \(\mathcal A\), first sum over the integer bases \(a\). A vertex residual with integer grid argument \(b\) contributes \(\sum_a q^{|Ma-b|}=\Theta_q(b)\). Next write each edge grid index as its residue \(r\pmod M\) plus an integer multiple of \(M\). Every vertex kernel is unchanged by those multiples, and the sum of that edge's weights is \(\sum_{k\equiv r\pmod M}q^{|k|}=\Theta_q(r)\). Therefore \(\mathcal A\) is exactly a finite sum over the \(M^{126}\) edge residue assignments, with edge factors \(\Theta_q(r_v)\) and vertex factors \(\Theta_q(M/2-r_v-r_{2v}-r_{2v+1})\). In particular, \(\mathcal A\) is finite; no discarded tail is involved.

Let \(A_h(r)\) denote the sum for a binary subtree of height \(h\) with prescribed incoming residue \(r\), excluding the weight of that incoming edge. Then

\[
\begin{aligned}
A_0(r)&=\Theta_q(M/2-r),\\
A_h(r)&=\sum_{u,v=0}^{M-1}
 \Theta_q(u)A_{h-1}(u)\Theta_q(v)A_{h-1}(v)
 \Theta_q(M/2-r-u-v)\quad(1\le h\le6).
\end{aligned}
\]

All kernel arguments here are read modulo \(M\). The tree has 127 vertices and 126 edges, its incoming root value is zero, and hence \(\mathcal A=A_6(0)\).

For \(-M\le k\le M\), let \(F_h(k)\) be the corresponding truncated Boolean subtree sum, now including the weight of the prescribed incoming edge. The exact recurrences are

\[
\begin{aligned}
F_0(k)&=q^{|k|+|M/2-k|},\\
F_h(k)&=q^{|k|}\sum_{i,j=-M}^{M}
 F_{h-1}(i)F_{h-1}(j)q^{|M/2-k-i-j|}
 \quad(1\le h\le6).
\end{aligned}
\]

At the root the additional incoming-edge factor is \(q^0=1\), so \(\mathcal F=F_6(0)\). Each displayed recurrence is obtained by fixing the two child edge values and multiplying their independent subtree contributions with the root residual. These recurrences therefore follow directly from the original sums.

Here are the arithmetic rules for enclosing these recurrences. They also explain the entire code below. Put \(D=2^{64}\), \(P=128\), and \(Q=2^P\). For \(x=29/2048\), the alternating exponential series has decreasing positive term magnitudes, since \(0<x<1\). Its truncations \(S_{15}=\sum_{j=0}^{15}(-x)^j/j!\) and \(S_{16}=\sum_{j=0}^{16}(-x)^j/j!\) satisfy \(S_{15}<q<S_{16}\). Define \(q_-=\lfloor DS_{15}\rfloor/D\) and \(q_+=\lceil DS_{16}\rceil/D\). Their numerators, computed exactly below, are respectively 18187375975531137195 and 18187375975531137196. In particular \(0<q_-<q<q_+<1\).

The integer arrays `pl` and `pu` start with \(Q\) and repeatedly multiply by \(q_-\) with downward rounding and by \(q_+\) with upward rounding, respectively. Thus `pl[j]` is at most \(Qq_-^j\), and `pu[j]` is at least \(Qq_+^j\). The code verifies `pu[M] < Q`. For each \(0\le r<M\), it sets

\[
T[r]=\left\lceil
 \frac{Q\bigl(\mathrm{pu}[r]+\mathrm{pu}[M-r]\bigr)}
 {Q-\mathrm{pu}[M]}\right\rceil.
\]

The numerator overestimates the corresponding powers, and the positive denominator underestimates \(Q(1-q_+^M)\). It follows that \(T[r]/Q\ge\Theta_{q_+}(r)\ge\Theta_q(r)\). The last inequality also follows term by term from the convergent nonnegative series defining \(\Theta\).

The routine `conv(a,b)` computes the exact ordinary convolution of two nonnegative integer arrays with positive maxima; its assertion checks the positive-maxima premise on every call. To see this, let \(H=\min(\operatorname{len}(a),\operatorname{len}(b))\max(a)\max(b)\). Every convolution coefficient is at most \(H\). Since both maxima are positive integers, \(H\) also bounds every input entry. The chosen byte width gives a radix \(B=256^{\mathrm{width}}>H\). Thus the input entries fit in their allocated digits. The packed integers are \(\sum_i a_iB^i\) and \(\sum_j b_jB^j\); their exact integer product has each convolution coefficient as one radix-\(B\) digit, with no carry between digits. Unpacking therefore yields the exact convolution. Its length is \(\operatorname{len}(a)+\operatorname{len}(b)-1\). The routine `circular` is used only on two arrays of length \(M\), so reducing their ordinary convolution modulo \(X^M-1\) requires adding just coefficients with indices \(r\) and \(r+M\). This is exactly its implementation.

In the code, `A` is an integer upper enclosure for the exact array \(A_h\): the invariant is \(A_h(r)\le2^{\mathrm{eA}}\mathrm{A}[r]/Q\). Initially `eA = 0`, and this follows from the kernel bound. In one update, `b[r] = ceil(T[r]*A[r]/Q)` gives an upper enclosure for the product \(\Theta_q(r)A_h(r)\) at the same scale \(2^{\mathrm{eA}}/Q\). Two exact circular convolutions then produce a nonnegative integer array `raw` for which the next exact array is bounded by \(2^{2\mathrm{eA}}\mathrm{raw}/Q^3\), after the permutation \(r\mapsto M/2-r\). For the chosen nonnegative integer `shift`, replacing `raw` by \(\lceil\mathrm{raw}/2^{\mathrm{shift}}\rceil\) and replacing `eA` by \(2\mathrm{eA}+\mathrm{shift}-2P\) preserves the stated invariant. Upward rounding is used at every inexact upper operation.

For the lower computation, the invariant is \(F_h(k)\ge2^{\mathrm{eF}}\mathrm{F}[k+M]/Q\). It holds at height zero by the bound on `pl`. If `c = conv(F,F)`, then its index \(j\) corresponds to the sum of child values \(j-2M\). The two integer recurrences used in the code are

\[
\begin{aligned}
\ell_0&=c_0,&
\ell_j&=c_j+\lfloor q_-\ell_{j-1}\rfloor\quad(1\le j\le4M),\\
r_{4M}&=0,&
r_j&=\lfloor q_-(c_{j+1}+r_{j+1})\rfloor\quad(0\le j<4M).
\end{aligned}
\]

Induction from the two ends gives \(\ell_j+r_j\le\sum_{i=0}^{4M}c_iq_-^{|j-i|}\). For an incoming value \(k\), the desired residual argument corresponds to index \(j=M/2-k+2M\), which lies between \(3M/2\) and \(7M/2\), within the available array. Multiplying this lower sum by `pl[abs(k)]/Q` and rounding down gives `raw[k+M]`. Positivity, \(q_-\le q\), and the preceding invariant imply that the next exact message is at least \(2^{2\mathrm{eF}}\mathrm{raw}[k+M]/Q^2\). Replacing `raw` by \(\lfloor\mathrm{raw}/2^{\mathrm{shift}}\rfloor\) and replacing `eF` by \(2\mathrm{eF}+\mathrm{shift}-P\) preserves the lower invariant. Every rounding here is downward. No lower error estimate or floating approximation is assumed.

The `bit_length` shifts merely keep the stored arrays bounded in size. The preceding algebra proves their validity for any nonnegative shift, so selecting them from the exact computed maximum introduces no approximation beyond the explicitly directed division. Negative values of `eA` or `eF` are ordinary exact powers of two.

The following complete Python program reproduces the certificate. `Fraction` and Python integers perform all arithmetic exactly. No floating-point operation, numerical quadrature, or FFT occurs.

```python
from fractions import Fraction

M, P, D = 1024, 128, 1 << 64
Q = 1 << P
x = Fraction(29, 2 * M)
term = total = Fraction(1)
for j in range(1, 17):
    term *= -x / j
    total += term
    if j == 15:
        lo = total
hi = total
qn = lo.numerator * D // lo.denominator
qu = -(-hi.numerator * D // hi.denominator)
assert (qn, qu) == (18187375975531137195, 18187375975531137196)
assert 0 < qn < qu < D

def ceildiv(a, b):
    return (a + b - 1) // b

def conv(a, b):
    assert max(a) > 0 and max(b) > 0
    width = (min(len(a), len(b)) * max(a) * max(b)).bit_length()
    width = max(1, (width + 7) // 8)
    aa = int.from_bytes(b''.join(v.to_bytes(width, 'little') for v in a), 'little')
    bb = aa if a is b else int.from_bytes(b''.join(v.to_bytes(width, 'little') for v in b), 'little')
    n = len(a) + len(b) - 1
    data = (aa * bb).to_bytes(width * n, 'little')
    return [int.from_bytes(data[i * width:(i + 1) * width], 'little') for i in range(n)]

def circular(a, b):
    c = conv(a, b)
    return [c[i] + (c[i + M] if i + M < len(c) else 0) for i in range(M)]

pl = [Q]
for j in range(5 * M // 2):
    pl.append(qn * pl[-1] // D)
pu = [Q]
for j in range(M):
    pu.append(ceildiv(qu * pu[-1], D))
assert pu[M] < Q
T = [ceildiv(Q * (pu[r] + pu[M - r]), Q - pu[M]) for r in range(M)]
A = [T[(M // 2 - r) % M] for r in range(M)]
eA = 0
for h in range(1, 7):
    b = [ceildiv(T[r] * A[r], Q) for r in range(M)]
    c = circular(b, b)
    d = circular(c, T)
    raw = [d[(M // 2 - r) % M] for r in range(M)]
    shift = max(0, max(raw).bit_length() - P)
    A = [ceildiv(v, 1 << shift) for v in raw]
    eA = 2 * eA + shift - 2 * P

F = [pl[abs(k) + abs(M // 2 - k)] for k in range(-M, M + 1)]
eF = 0
for h in range(1, 7):
    c = conv(F, F)
    left, right = c.copy(), [0] * len(c)
    for i in range(1, len(c)):
        left[i] += qn * left[i - 1] // D
    for i in range(len(c) - 2, -1, -1):
        right[i] = qn * (c[i + 1] + right[i + 1]) // D
    raw = []
    for k in range(-M, M + 1):
        i = M // 2 - k + 2 * M
        raw.append(pl[abs(k)] * (left[i] + right[i]) // Q)
    shift = max(0, max(raw).bit_length() - P)
    F = [v >> shift for v in raw]
    eF = 2 * eF + shift - P

a, f = A[0], F[M]
assert (a, eA) == (26783533101085606039631146380587783189, 191)
assert (f, eF) == (215224267334044344572902669513147900120, 122)
assert f > 0
lhs, rhs = 729 * a * 5 ** 127, f * 8 ** 127
if eA >= eF:
    lhs <<= eA - eF
else:
    rhs <<= eF - eA
assert lhs < rhs
assert rhs // lhs == 1564
print('PASS')
print('upper root:', a, eA)
print('lower root:', f, eF)
print('integer margin:', rhs // lhs)
```

```text

upper root: 26783533101085606039631146380587783189 191
lower root: 215224267334044344572902669513147900120 122
integer margin: 1564
```

For clarity, write \(a=26783533101085606039631146380587783189\) and \(f=215224267334044344572902669513147900120\) for these two final stored integers. The proved invariants and the output give \(\mathcal A\le a2^{191}/2^{128}=a2^{63}\) and \(\mathcal F\ge f2^{122}/2^{128}=f/64>0\). The last assertion in the program is the exact finite integer comparison \(729a2^{69}5^{127}<f8^{127}\); indeed the floor of the right side divided by the left side is 1564.
