## Statement

Let \(L\) be a rank-three lattice, let \(\chi:L\to\mathbb Z/2\mathbb Z\) be a nonzero character, and set \(M=\ker\chi\). Let \(E\) be a full-dimensional tetrahedron such that \(E\cap L\) consists of its four vertices, exactly two of character zero and two of character one. Put \(Q=2E\) and \(B=Q\cap M\). For \(j\in M\), use the oriented, zero-inclusive reflection convention \(r_B(j)=|\{v\in M:j+v,j-v\in B\}|\), and suppose \(\max_{j\in M}r_B(j)\le3\).

These are the inner-body source objects under the aliases \(E=Q/2\), \(L=\mathbb Z^3+\mathbb Z(u/2)\), and \(M=\mathbb Z^3\). The coordinates in all normal forms below are coordinates in a basis of \(L\). Thus an integer coordinate triple is an \(L\)-point; membership of a reflection center in \(M\) must additionally be checked with \(\chi\).

Call the source character aligned if there is an affine integer-valued functional on \(L\), taking values in \([0,1]\) on \(E\), whose linear part reduces modulo two to \(\chi\). Such a functional is primitive, since it takes both zero and one at lattice vertices. Up to the source lattice transformations proved below, the following classification is exact.

If the character is aligned, one can write

\(E=\operatorname{conv}\{0,e_1,e_3,(p,q,1)\}\), with \(q\ge1\), \(0\le p<q\), \(\gcd(p,q)=1\), and \(\chi(x,y,z)=z\pmod2\).

In this case \(Q\cap M\) consists exactly of

\(0,e_1,2e_1,2e_3,(p,q,2),(2p,2q,2)\).

Every member of this family satisfies all the source hypotheses and has reflection maximum three, with no bound on \(q\).

If the character is not aligned, the source has the same tetrahedron normal form, but its character is one of \(y+z\), \(x\), or \(x+y\), reduced modulo two. Its parameters occur in exactly the following table. An entry lists all allowed values of \(p\) at the indicated \(q\); an empty entry means none.

| \(q\) | \(\chi=y+z\) | \(\chi=x\) | \(\chi=x+y\) |
|---|---|---|---|
| 2 | 1 | | 1 |
| 3 | | | 2 |
| 4 | 1, 3 | 3 | 1 |
| 5 | | 3 | 2 |
| 6 | | 5 | |
| 7 | | 3, 5 | 2, 4 |
| 8 | 1, 3, 5, 7 | 5 | 1, 5 |
| 9 | | 5, 7 | 2, 4 |
| 10 | | | 3, 7 |
| 11 | | 3, 5, 7, 9 | 4, 8 |
| 12 | 5, 7 | 5 | |
| 13 | | 3, 7, 9, 11 | 2, 6 |
| 14 | | 5 | 3 |
| 15 | | 7, 13 | |
| 16 | 7, 9 | | |
| 17 | | 5, 7 | |

There are respectively eleven, twenty-two, and seventeen entries in the three character columns, for fifty raw parameter/character triples \((p,q,\chi)\). These are not asserted to be fifty lattice-isomorphism classes. Different choices of the White width direction, ordering, or lattice basis may give different table entries for equivalent sources. Every unaligned source admits a representation in the table, and every table entry satisfies the source hypotheses. The number \(q\) is the normalized \(L\)-volume of \(E\), so its bound by seventeen is invariant under the allowed lattice isomorphisms.

## Proof

We first specify the source transformations. For \(v\in L\), translating \(E\) to \(E-v\) translates \(Q\cap M\) to \((Q\cap M)-2v\), because \(2v\in M\). This is a translation by a vector of the counted lattice, so preserves every reflection count. If \(v\in M\), vertex characters are unchanged; if \(v\in L\setminus M\), every vertex character is interchanged. The latter is the allowed color interchange: it is implemented by translating the tetrahedron, not by replacing the linear character by the non-character \(\chi+1\). A linear lattice isomorphism \(A\) sends \((L,M,E,\chi)\) to \((A L,A M,A E,\chi\circ A^{-1})\); it induces a bijection on reflection centers and displacements. These observations justify all translations and basis changes below.

For compatibility with the original segment formulation, if a color interchange is applied to a pair \((E,s)\), where \(s=u/2\), one can use \((E-v,-s)\) with \(\chi(v)=1\). The corresponding middle tetrahedron and segment body are translated by \(-v-s\in M\), and the source by \(-2v\in M\). Indeed, writing the original middle tetrahedron as the convex hull of the character-zero vertices and the character-one vertices shifted by \(s\), the new middle tetrahedron has the two groups \(v_1-v\) and \(v_0-v-s\). These are exactly the old groups translated by \(-v-s\); also \(E-v+[0,-s]=E+[0,s]-v-s\). This compatibility statement is not used to infer any segment equality.

Apply White's theorem in the lattice \(L\), using the precise primary-source statement in EXTERNAL SOURCES. It supplies a primitive integer height functional with two vertices at height zero and two at height one, and each within-layer edge is primitive. Choose the height-zero edge to contain a character-zero vertex, reversing the two layers if necessary, and translate that vertex to zero. Its primitive edge direction can be taken as \(e_1\) in a basis of the rank-two height-zero lattice. The height-one vector to either vertex of the other layer extends that plane basis to a basis of \(L\): its height is one. Take that vector as \(e_3\). The fourth vertex then has coordinates \((p_0,q_0,1)\), with \(q_0\ne0\) by full dimension. Reversing the second basis vector makes \(q_0>0\), and replacing that vector by itself plus an integer multiple of \(e_1\) reduces the first coefficient modulo \(q_0\). We obtain the displayed normal form with \(0\le p<q\). The other within-layer edge has direction \((p,q,0)\), whose primitivity gives \(\gcd(p,q)=1\). The determinant of the three nonzero vertices has absolute value \(q\).

Conversely, every tetrahedron in this normal form is empty in \(L\). Its only possible integer heights are zero and one, and its sections at these heights are the primitive segments \([0,e_1]\) and \([e_3,(p,q,1)]\). Thus its complete \(L\)-census consists of its four vertices.

There are two ways that the two characters can be distributed across the two White layers. If each layer is monochromatic, choose the character-zero layer as the height-zero layer. The character then has the form \(\chi(x,y,z)=\beta y+z\pmod2\), with \(\beta\in\{0,1\}\) and \(\beta q\) even. If each layer has both characters, choose its character-zero vertex as the origin in the bottom layer and as \(e_3\) in the top layer. Then \(\chi(x,y,z)=x+\beta y\pmod2\), where \(p+\beta q\) is odd. These choices cover all cases; the subsequent plane shear only changes the value of \(\beta\), which is still either zero or one.

We identify precisely which of these cases are character aligned. If an aligning functional exists in these coordinates, replace it by one minus itself when necessary so that it vanishes at the origin. Its value at each of the four vertices is then the integer representative zero or one of that vertex's character. These four values determine an affine functional uniquely. For \(\chi=z\), the functional is \(z\), so this case is aligned. For \(\chi=y+z\), its required values at the vertices force its coefficients to be \((0,0,1)\), whose reduction is \(z\), not \(y+z\). Thus this case is unaligned.

For a character \(x+\beta y\), the required functional is \(x+(1-p)y/q\). Its coefficients are integers with the required parity if and only if \(p+\beta q=1\). Indeed, when \(q>1\), integrality and \(0\le p<q\) force \(p=1\), and parity then forces \(\beta=0\). When \(q=1\), the normal form has \(p=0\), and the valid aligned choice is \(\beta=1\). These aligned cases can be put into the stated \(\chi=z\) form by explicit lattice isomorphisms. For \(q>1,p=1,\beta=0\), use \((x,y,z)\mapsto(z,y,x)\). For \(q=1,p=0,\beta=1\), use \((x,y,z)\mapsto(z-y,y,x+y)\). Both matrices have determinant minus one. Reordering the two vertices within the new layers gives the claimed tetrahedron form, respectively with parameters \((1,q)\) and \((0,1)\), and the new character is the last coordinate modulo two.

We next give a complete lattice census of \(Q=2E\) before applying the character. Its height-zero and height-two sections are primitive segments of lattice length two, with the six points listed in the aligned case. Its height-one section is the parallelogram

\(\mathcal C=e_3+[0,e_1]+[0,(p,q,0)]\).

At an integer second coordinate \(k\) with \(1\le k<q\), its first-coordinate interval is \([pk/q,1+pk/q]\). The two endpoints are nonintegers because \(\gcd(p,q)=1\), so this interval contains exactly \(\lceil pk/q\rceil\). At second coordinate zero or \(q\), there are the four vertices of the parallelogram. Hence its complete \(L\)-census is

\(e_3,e_1+e_3,(p,q,1),(p+1,q,1)\), together with \((\lceil pk/q\rceil,k,1)\) for \(1\le k<q\).

This retains all boundary points. For \(q=1\) the intermediate list is empty. Filtering this census by \(\chi=0\) gives the full source census in \(M\).

When \(\chi=z\), all height-one points are discarded and precisely the six even-height points remain. A reflected pair with endpoints at different heights has center at height one and thus does not have its center in \(M\). Within either remaining three-point segment, only the middle point has a nonzero unordered reflected pair. Consequently the reflection maximum is exactly three, with the zero displacement included. This proves both the claimed six-point census and the sufficiency of the whole aligned family.

For the unaligned cases we first bound the determinant without any enumeration. The finite set \(\mathcal C\cap M\) is centrally symmetric. Its symmetry sends a point \(x\) to \((p+1,q,2)-x\). The vector \((p+1,q,2)\) belongs to \(M\) in every allowed character case: for \(\beta y+z\) this uses \(\beta q\) even, and for \(x+\beta y\) it uses \(p+\beta q\) odd. Thus the symmetry maps counted lattice points to counted lattice points.

Accepted fact 768d9712b73c4ab7 gives the inequality \(|A|\le3\cdot2^k-v_A\) for a full-dimensional lattice-convex set in a rank-\(k\) lattice with reflection maximum at most three and with \(v_A\) hull vertices. To apply it to this section, translate a counted point to zero and choose a basis of the lattice in the section's affine span. Every intrinsic reflection is an ambient reflection in \(M\), so the source bound is inherited. If its hull has dimension two, central symmetry forces at least four vertices, giving at most \(12-4=8\) points. If its hull has dimension one or zero, the corresponding bounds are four and one. Empty sections cause no difficulty. Therefore \(|\mathcal C\cap M|\le8\).

For \(\chi=y+z\), the condition on the four vertex colors forces \(q\) to be even. All four vertices of \(\mathcal C\) have character one. In its intermediate list, exactly the odd values of \(k\) have character zero, giving \(|\mathcal C\cap M|=q/2\). The bound just proved implies \(q\le16\).

For \(\chi=x+\beta y\), put \(\ell=p+\beta q\). It is an odd positive integer, is coprime to \(q\), and is at most \(2q-1\). The two counted parallelogram vertices are \(e_3\) and \((p+1,q,1)\). An intermediate point has character zero precisely when \(\lceil\ell k/q\rceil\) is even, since \(\lceil pk/q\rceil+\beta k=\lceil(p+\beta q)k/q\rceil\). Write \(m\) for the number of such integers \(k\), with \(1\le k<q\). Thus \(|\mathcal C\cap M|=m+2\), and \(m\le6\). The aligned case \(\ell=1\) was already separated.

We prove that \(m>q/6\) whenever \(\ell\ne1\). First suppose \(1<\ell<q\). Write \(\ell=2r+1\) and \(a=\lfloor q/\ell\rfloor\), where \(r,a\ge1\). Each of the \(r\) even ceiling levels contributes the integers in an interval \(((2i-1)q/\ell,2iq/\ell)\), for \(1\le i\le r\). Both endpoints are nonintegers, and its length is \(q/\ell\), so it contains at least \(a\) integers. These intervals are disjoint, giving \(m\ge ra\). Also \(q<(a+1)(2r+1)\), and

\[
6ra-(a+1)(2r+1)
=a(4r-1)-2r-1
\ge2r-2\ge0.
\]

It follows that \(m\ge ra>q/6\).

If \(q<\ell<2q\), put \(\ell'=2q-\ell\), an odd positive integer less than \(q\) and coprime to \(q\). For every \(1\le k<q\), the number \(\ell'k/q\) is not an integer, and

\(\lceil\ell k/q\rceil=2k-\lceil\ell'k/q\rceil+1\).

Thus \(m\) counts the odd ceiling levels for \(\ell'k/q\). If \(\ell'=1\), it equals \(q-1>q/6\), since \(q\ge2\). Otherwise write \(\ell'=2r+1\) and \(a=\lfloor q/\ell'\rfloor\), with \(r,a\ge1\). There are \(r+1\) odd ceiling levels. Each of their intervals contains at least \(a\) integers from \(1,\ldots,q-1\). For the first and last intervals, this remains true despite excluding zero and \(q\): their counts are respectively \(\lfloor q/\ell'\rfloor\) and \(\lceil q/\ell'\rceil-1\), both equal to \(a\). The other intervals have noninteger endpoints as above. Hence \(m\ge(r+1)a\ge ra>q/6\), by the same inequality with \(\ell'\) in place of \(\ell\). The possible equality \(\ell=q\) is incompatible with coprimality unless \(q=1\), in which case \(\ell=1\) was already aligned.

Combining \(m>q/6\) and \(m\le6\) proves \(q<36\), hence \(q\le35\), for every unaligned cross-character case. Together with the earlier bound for \(y+z\), this is an independently proved cutoff for every unaligned source.

It remains to perform a finite exact check for \(1\le q\le35\). The following complete certificate uses only integer arithmetic and the Python standard library. The function `source_points` is the full census derived above. The additional bounding-box enumeration checks that census independently against the four exact membership inequalities for \(2E\): \(y\ge0\), \(qz-y\ge0\), \(qx-py\ge0\), and \(q(2-x-z)+py\ge0\). The box used contains every vertex and therefore contains \(2E\).

A pair of integer coordinate triples has its midpoint in \(M\) exactly when every coordinate of its sum is even and the character of its coordinatewise half-sum is zero. Both tests occur in the certificate. By convexity, any such midpoint of source points is again a source point. Its reflection count is one plus twice the number of distinct unordered endpoint pairs there. Thus a repeated midpoint is exactly the forbidden event; this also checks cross-height pairs, and the zero displacement is handled by the preceding count formula.

```python
from itertools import combinations
from math import gcd

def parity(point, character):
    return sum(a*b for a, b in zip(point, character)) % 2

def source_points(p, q, character):
    points = [(0,0,0),(1,0,0),(2,0,0),
              (0,0,2),(p,q,2),(2*p,2*q,2),
              (0,0,1),(1,0,1),(p,q,1),(p+1,q,1)]
    points += [((p*k+q-1)//q,k,1) for k in range(1,q)]
    return [v for v in points if parity(v, character) == 0]

def reflection_at_most_three(points, character):
    centers = set()
    for x, y in combinations(points, 2):
        total = tuple(a+b for a,b in zip(x,y))
        if any(a % 2 for a in total):
            continue
        center = tuple(a//2 for a in total)
        if parity(center, character):
            continue
        if center in centers:
            return False
        centers.add(center)
    return True

characters = [(0,1,1),(1,0,0),(1,1,0)]
expected = {
 2: ((1,), (), (1,)),
 3: ((), (), (2,)),
 4: ((1,3), (3,), (1,)),
 5: ((), (3,), (2,)),
 6: ((), (5,), ()),
 7: ((), (3,5), (2,4)),
 8: ((1,3,5,7), (5,), (1,5)),
 9: ((), (5,7), (2,4)),
10: ((), (), (3,7)),
11: ((), (3,5,7,9), (4,8)),
12: ((5,7), (5,), ()),
13: ((), (3,7,9,11), (2,6)),
14: ((), (5,), (3,)),
15: ((), (7,13), ()),
16: ((7,9), (), ()),
17: ((), (5,7), ())}
observed = {}
for q in range(1,36):
    row = [[],[],[]]
    for p in range(q):
        if gcd(p,q) != 1:
            continue
        vertices = [(0,0,0),(1,0,0),(0,0,1),(p,q,1)]
        for index, character in enumerate(characters):
            if sum(parity(v,character) for v in vertices) != 2:
                continue
            if character[0] == 1 and p+character[1]*q == 1:
                continue
            points = source_points(p,q,character)
            assert len(points) == len(set(points))
            direct = []
            for x in range(2*max(1,p)+1):
                for y in range(2*q+1):
                    for z in range(3):
                        if parity((x,y,z),character):
                            continue
                        if y >= 0 and q*z-y >= 0 and q*x-p*y >= 0 and q*(2-x-z)+p*y >= 0:
                            direct.append((x,y,z))
            assert set(points) == set(direct)
            if reflection_at_most_three(points,character):
                row[index].append(p)
    if any(row):
        observed[q] = tuple(tuple(v) for v in row)
assert observed == expected
counts = tuple(sum(len(row[i]) for row in observed.values()) for i in range(3))
assert counts == (11,22,17)
assert sum(counts) == 50 and max(observed) == 17
print('Exact census verified:', sum(counts), 'raw triples; column counts', counts, '; maximum q', max(observed))
```

Executing this certificate gives `Exact census verified: 50 raw triples; column counts (11, 22, 17) ; maximum q 17`. The loops include every normal-form character and parameter remaining after the independent determinant bound, reject every failed source using an exact repeated midpoint, and verify every survivor with the complete source census. Conversely, the emptiness, two-plus-two vertex split, and reflection bound of every displayed survivor are all checked or proved above. This proves the classification with the stated raw-triple convention.

## External sources

Victor Batyrev and Johannes Hofscheier, *A generalization of a theorem of G. K. White*, arXiv:1004.3411v1, Theorem 1.1: [primary paper and exact theorem](https://arxiv.org/html/1004.3411v1).

The precise equivalence used is that a three-dimensional lattice tetrahedron is empty if and only if it is affine-unimodularly equivalent to a tetrahedron with two vertices at integer height zero and two at integer height one, with both within-layer edges containing no lattice points other than their endpoints. The statement was checked in Theorem 1.1 of this version. It applies after choosing any basis of the rank-three lattice \(L\), because \(E\) is full-dimensional and its complete \(L\)-census consists of its four vertices. The subsequent normal form, character transformations, determinant cutoff, and reflection census are proved in this packet. No assertion that all empty tetrahedra belong to the narrower Reeve family \(\operatorname{conv}\{0,e_1,e_2,(1,1,q)\}\) is used.
