## Statement

Let \(n=10\), and let
\[
P=\left\{x\in\mathbb R_{\ge0}^{10}:\sum_{i=1}^{10}x_i\le20\right\},
\qquad
D=P\cap\mathbb Z^{10}.
\]
For every \(j\in D\), use precisely
\(A_j=\{u\in\mathbb Z^{10}:0\le u\le j,\ j+u\in D\}\) and
\(M_j=|A_j-A_j|\), counting each distinct difference once.
For \(k\ge0\) and \(y\in\mathbb Z_{\ge0}^{10}\), put
\[
E_{j,k}=\{u\in\mathbb Z_{\ge0}^{10}:2^k u\in A_j\},
\qquad
B_{j,k,y}=\{\epsilon\in\{0,1\}^{10}:2y+\epsilon\in E_{j,k}\}.
\]
If \(B\subseteq\{0,1\}^{10}\), let
\(\operatorname{disj}(B)=|\{(\epsilon,\eta)\in B^2:
\epsilon_i\eta_i=0\text{ for all }i\}|\), with the pair ordered.
Use the specified weight
\[
\gamma_j
=1+\sum_{k\ge0}\
\sum_{\substack{y\in\mathbb Z_{\ge0}^{10}\\B_{j,k,y}\ne\varnothing}}
\bigl(\operatorname{disj}(B_{j,k,y})-1\bigr).
\]
The exact all-center counts are
\[
\begin{aligned}
|D|&=30045015,\\
\sum_{j\in D}M_j&=89473785951,\\
\sum_{j\in D}\gamma_j&=34823261731,\\
\sum_{j\in D}\gamma_jM_j&=1\,015\,240\,625\,292\,151.
\end{aligned}
\]
Consequently
\[
\begin{aligned}
2^{10}\sum_{j\in D}\gamma_jM_j
&=1039606400299162624\\
&<1046265421056820965
=|D|\sum_{j\in D}\gamma_j.
\end{aligned}
\]
The right side exceeds the left side by \(6\,659\,020\,757\,658\,341\).
For comparison, the exact second moment is
\(\sum_{j\in D}M_j^2=2\,839\,381\,073\,441\,231\), and this seed satisfies
\[
\begin{aligned}
2^{10}\sum_{j\in D}M_j^2
&=2907526219203820544\\
&>2688241241004584265
=|D|\sum_{j\in D}M_j.
\end{aligned}
\]
Nevertheless, the center \(j=(1,\ldots,1)\) has \(M_j=59049\), and
\(2^{10}M_j=60466176>|D|\). Thus this seed obeys the optimized corner inequality.

## Proof

The set \(P\) is the simplex with vertices \(0,20e_1,\ldots,20e_{10}\).
It is compact, convex, full-dimensional, and contained in the nonnegative orthant. Its complete integer intersection is exactly the displayed \(D\).
If \(0\le z\le j\in D\) are integer vectors, then
\(\sum_i z_i\le\sum_i j_i\le20\), so \(z\in D\).
This verifies the downset hypothesis and includes every boundary lattice point.
Stars and bars, with a nonnegative slack coordinate, gives
\(|D|=\binom{30}{10}=30045015\).

We first derive counts that apply to every center. Write
\(s=\sum_i j_i\), \(t=20-s\), and let
\(\lambda=(\lambda_1,\ldots,\lambda_r)\) be the positive coordinates of \(j\), listed in nondecreasing order. Thus \(0\le r\le10\),
\(1\le\lambda_1\le\cdots\le\lambda_r\), and
\(\sum_i\lambda_i=s\le20\).
The empty list occurs exactly at \(j=0\).
All zero coordinates of \(j\) force the corresponding coordinates of every forward displacement and every Boolean vector to be zero. Deleting these deterministic zero coordinates preserves \(M_j\) and \(\gamma_j\). In the formulas below, write \(M(\lambda)=M_j\) and \(\gamma(\lambda)=\gamma_j\) for any permutation of this center. The dimension in the proposed selector remains ten.

In these coordinates the original corner set is exactly
\[
A_j=\left\{u\in\mathbb Z_{\ge0}^{r}:
u_i\le\lambda_i\ \text{for all }i,\
\sum_i u_i\le t\right\}.
\tag{1}
\]
It is a downset. For an integer vector \(v\), let \(v^+\) and \(v^-\) be its coordinatewise positive and negative parts. Then
\(v\in A_j-A_j\) if and only if \(v^+,v^-\in A_j\).
Indeed, if \(v=a-b\), then \(v^+\le a\) and \(v^-\le b\), and downward closure applies. Conversely, \(v=v^+-v^-\).
The two parts have disjoint supports and are uniquely determined by \(v\).
This gives a bijection, so the subsequent count is of distinct differences.

For \(I\subseteq[r]\), let \(F_\lambda(I;t)\) count the assignments of positive integers \(a_i\) to \(i\in I\) with
\(a_i\le\lambda_i\) and \(\sum_{i\in I}a_i\le t\).
Set \(\binom{b}{a}=0\) unless \(b\ge a\ge0\), and \(\binom{b}{0}=1\) for \(b\ge0\).
Inclusion-exclusion after replacing \(a_i\) by \(a_i-1\) gives the exact formula
\[
F_\lambda(I;t)
=\sum_{T\subseteq I}(-1)^{|T|}
\binom{\,t-\sum_{i\in T}\lambda_i\,}{|I|}.
\tag{2}
\]
To check (2), without upper bounds the nonnegative variables \(a_i-1\) have sum at most \(t-|I|\), hence there are \(\binom{t}{|I|}\) assignments. A violation in coordinate \(i\) means \(a_i-1\ge\lambda_i\); shifting by \(\lambda_i\) in each selected violating coordinate gives exactly the corresponding binomial term. The convention handles an impossible shifted sum. In particular \(F_\lambda(\varnothing;t)=1\), including \(t=0\).

Choose the support \(I\) of \(v^+\) and the support \(J\) of \(v^-\). They are disjoint, and the two sum constraints in (1) are separate. The difference count is therefore
\[
M(\lambda)
=\sum_{I\subseteq[r]}
\ \sum_{J\subseteq[r]\setminus I}
F_\lambda(I;t)\,F_\lambda(J;t).
\tag{3}
\]
This includes zero once and both orientations of every nonzero difference.

Here is an independent direct formula for the weight, including every dyadic depth. For integers \(a,R\ge0\), let
\[
Q(a,R)
=\sum_{h=0}^{\min(a,2R)}\binom ah
\sum_{b=\max(0,h-R)}^{\min(h,R)}\binom hb.
\tag{4}
\]
It counts ordered disjoint pairs of subsets of an \(a\)-element set, each subset having size at most \(R\). Namely, choose their union of size \(h\), and then choose the first subset of size \(b\) inside that union; the second subset is its complement in the union. The restrictions on \(b\) are precisely \(b\le R\) and \(h-b\le R\). This accounts for every pair once and gives \(Q(a,0)=1\).

For a scale \(q\in\{1,2,4,8\}\), define
\[
\begin{aligned}
\mathcal Y_{\lambda,q}
&=\left\{y\in\mathbb Z_{\ge0}^{r}:
2qy_i\le\lambda_i\ \text{for all }i,\
2q\sum_i y_i\le t\right\},\\
a_{\lambda,q}(y)
&=\left|\{i\in[r]:2qy_i+q\le\lambda_i\}\right|,\\
R_{\lambda,q}(y)
&=\left\lfloor t/q\right\rfloor-2\sum_i y_i.
\end{aligned}
\tag{5}
\]
For \(q=2^k\), (1) shows that
\(E_{j,k}=\{u\ge0:u_i\le\lfloor\lambda_i/q\rfloor,\
\sum_i u_i\le\lfloor t/q\rfloor\}\).
A nonempty Boolean block has \(y\in\mathcal Y_{\lambda,q}\). This is an equivalence: any nonempty block contains its zero Boolean vector, and the inequalities in (5) are exactly the conditions for that zero vector. For such a \(y\), an allowed Boolean vector can use exactly the
\(a_{\lambda,q}(y)\) coordinates identified in (5), and has cardinality at most \(R_{\lambda,q}(y)\). Thus its ordered disjoint-pair count is exactly
\(Q(a_{\lambda,q}(y),R_{\lambda,q}(y))\), by (4).

Every \(u\in A_j\) has \(u_i\le10\), because
\(2u_i\le j_i+u_i\le s+\sum_i u_i\le20\).
It follows that \(E_{j,k}=\{0\}\) for every \(k\ge4\).
Each such depth has one nonempty Boolean block, whose disjoint-pair count is one, so the entire tail contributes zero. There are no omitted deeper terms. Consequently
\[
\gamma(\lambda)
=1+\sum_{q\in\{1,2,4,8\}}
\ \sum_{y\in\mathcal Y_{\lambda,q}}
\bigl(Q(a_{\lambda,q}(y),R_{\lambda,q}(y))-1\bigr).
\tag{6}
\]
This is the weight in the question, with its constant term and its subtraction of the zero ordered pair in every block unchanged. Formula (6) does not rely on any unverified injection or previous packet.

For completeness, the following describes the entire center census through explicit finite sums. If \(m_a\) is the number of occurrences of \(a\) in \(\lambda\), then its multiplicity among the original centers is
\[
\operatorname{mult}(\lambda)
=\frac{10!}{(10-r)!\prod_{a=1}^{20}m_a!}.
\tag{7}
\]
Every center occurs in exactly one such permutation class. For each
\(s=0,\ldots,20\), enumerate all nondecreasing positive lists \(\lambda\) of sum \(s\) and length at most ten. Use (2)-(3) for \(M(\lambda)\), (4)-(6) for \(\gamma(\lambda)\), and (7) for its multiplicity. This specifies both counts for every center, without replacing a corner by another set or counting a difference representation twice.

The finite arithmetic in both census groupings can be audited with the following standalone implementation of (2)-(7). It uses integer arithmetic throughout. In the computation of (3), the array named Z is the subset sum
\(Z(B)=\sum_{J\subseteq B}F_\lambda(J;t)\), so the final expression
\(\sum_I F_\lambda(I;t)Z([r]\setminus I)\) is exactly (3).
The partition generator enumerates each list in (7) once.
Every loop is finite, and the asserts check the claimed census totals and the strict margin.

from functools import lru_cache
from itertools import product
from math import comb, factorial

def partitions(s, least=1, slots=10):
    if s == 0:
        yield ()
    elif slots:
        for a in range(least, s + 1):
            for tail in partitions(s - a, a, slots - 1):
                yield (a,) + tail

def choose(a, b):
    return comb(a, b) if a >= b >= 0 else 0

@lru_cache(None)
def Q(r, R):
    return sum(comb(r, h) * sum(
        comb(h, a) for a in range(max(0, h - R), min(h, R) + 1))
        for h in range(min(r, 2 * R) + 1))

def local_counts(lam, t):
    r = len(lam)
    full = (1 << r) - 1
    subset_sums = [sum(lam[i] for i in range(r) if b >> i & 1)
                   for b in range(1 << r)]
    F = []
    for b in range(1 << r):
        c, value = b, 0
        while True:
            value += (-1) ** c.bit_count() * choose(
                t - subset_sums[c], b.bit_count())
            if c == 0:
                break
            c = (c - 1) & b
        F.append(value)
    Z = F.copy()
    for i in range(r):
        for b in range(1 << r):
            if b >> i & 1:
                Z[b] += Z[b ^ (1 << i)]

                value += Q(eligible, T - 2 * sum(y)) - 1
        increments.append(value)
    return M, 1 + sum(increments), increments
