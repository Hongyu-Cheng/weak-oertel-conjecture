## Statement

For $z=-2,-1,0,1,2$ let $K_z=[-r_z/2,r_z/2]\times[-H_z,H_z]$ with
$$
r=(1,51/50,51/50,203/200,101/100),\qquad
H=1+(3/800)(0,3,2,1,0).
$$
These are the actual sampled fibers of their canonical hull. The global ordinary raw maximum is $Q=812869/160000$, attained at $(0,0,0)$, where the only minimizing through-mark halfspaces are $\pm y-z/2\ge0$. The original mixed area is $M=814069/80000$ and $M-2Q=3/200$.

Each of the following two paths strictly decreases the actual normalized maximum for all sufficiently small $t>0$: replacing $3/800$ by $3/800-t$ in the height tent, or replacing only $H_{-1}$ by $H_{-1}-t$. The one-node path is compatible for $0<t<3/400$. Along the tent path the two old minimizing cap masses are $Q-At$ and total mass is $M-2At$ with $A=1223/200$. Along the one-node path these formulas hold with $A=51/50$. In either case the new raw maximum is at most $Q-At$.

## Proof

The width and height arrays have nonincreasing successive differences and are positive. Their piecewise-affine interpolation in $z$ thus gives an actual convex body with the prescribed rectangles. Taking the hull of its sampled fibers preserves those sections and projection. Summing the areas gives $M$.

For a cap through the origin with both continuous coefficients nonzero, reflect $x$ and $y$ to make those coefficients $p,q>0$. Write the cap as $p x+q y+\sigma b z\ge0$ with $b\ge0$, $\sigma=\pm1$, and normalize $p+q+b=1$. Let $\mathcal M$ be its cap area. Integrating the two rectangular coordinates, or twice taking the antiderivative of a positive part, gives
$$
2pq\mathcal M=\sum_z\sum_{s_x,s_y\in\{-1,1\}}s_xs_y
  \bigl(\sigma b z+s_xr_zp/2+s_y H_zq\bigr)_+^2 .
$$
For either sign split the closed parameter triangle by the twenty affine zero lines in this formula. On a cell the function $2pq(\mathcal M-Q)$ is a homogeneous quadratic in $(p,q,b)$. Triangulate each positive-area convex cell by a fan from its first vertex. On each nondegenerate triangle the sign of every nonzero linear form is determined by its value at the barycenter. Let $B_{jk}$ be the symmetric bilinear coefficient of this quadratic on triangle vertices $v_j,v_k$. In triangle barycentric coordinates $\lambda$, the value is $\sum_{jk}\lambda_j\lambda_k B_{jk}$. Thus nonnegative coefficients prove the bound, and equality requires every coefficient on the support of $\lambda$ to vanish. The exact arithmetic below checks that each all-zero support is confined to $p=0$ or $q=0$, which makes the bound strict for oblique continuous directions.

Each split clips an ordered convex polygon against both closed halfplanes and discards zero-area pieces. The retained interiors are disjoint by construction and cover the parameter simplex up to their edges, with all coefficients extended continuously to the edges. The clipping intersection along an edge with opposite endpoint signs $s,t$ has coordinates $(t v-s w)/(t-s)$ for endpoints $v,w$. This also covers lines meeting existing vertices since all zero endpoints are retained. The finite calculation uses exact rational arithmetic only and needs no imported certificate.

```python
from fractions import Fraction as F
from itertools import combinations

Z = range(-2, 3)
r = tuple(map(F, ("1", "51/50", "51/50", "203/200", "101/100")))
H = tuple(map(F, ("1", "809/800", "403/400", "803/800", "1")))
Q = F(812869, 160000)
M = F(814069, 80000)
rows = tuple(zip(Z, r, H))
assert 2 * sum(w*h for z,w,h in rows) == M
assert M - 2*Q == F(3, 200)
def dot(a,b):
    return sum(x*y for x,y in zip(a,b))

def area2(poly):
    return abs(sum(p[0]*q[1]-p[1]*q[0]
                   for p,q in zip(poly, poly[1:]+poly[:1])))

def clip(poly, a):
    out = []
    for p,q in zip(poly, poly[1:]+poly[:1]):
        s,t = dot(a,p), dot(a,q)
        if s >= 0:
            out.append(p)
        if s*t < 0:
            out.append(tuple((t*x-s*y)/(t-s) for x,y in zip(p,q)))
    return out

simplex = [tuple(F(i == j) for j in range(3)) for i in range(3)]
triangles = 0
for sign in (-1, 1):
    terms = [(sx*sy, (sx*w/2, sy*h, F(sign*z)))
             for z,w,h in rows for sx in (1,-1) for sy in (1,-1)]
    cells = [simplex]
    for _,a in terms:
        cells = [part for poly in cells for s in (1,-1)
                 if area2(part := clip(poly, tuple(s*x for x in a)))]
    assert len(cells) == 43 and sum(map(area2,cells)) == 1
    for poly in cells:
        for i in range(1, len(poly)-1):
            tri = [poly[0], poly[i], poly[i+1]]
            if not area2(tri):
                continue
            triangles += 1
            center = tuple(sum(p[j] for p in tri)/3 for j in range(3))
            active = [(k,a) for k,a in terms if dot(a,center) > 0]
            B = [[sum(k*dot(a,p)*dot(a,q) for k,a in active)
                  -Q*(p[0]*q[1]+p[1]*q[0]) for q in tri] for p in tri]
            assert all(c >= 0 for row in B for c in row)
            for size in (1,2,3):
                for J in combinations(range(3),size):
                    if all(B[j][k] == 0 for j in J for k in J):
                        assert any(all(tri[j][axis] == 0 for j in J)
                                   for axis in (0,1))
assert triangles == 138

def clamp(a, upper):
    return max(F(0), min(a, upper))

for vertical in (True, False):
    axes = [(z,h,w) if vertical else (z,w/2,2*h) for z,w,h in rows]
    knots = sorted({F(0)} | {s*a/z for z,a,b in axes if z for s in (-1,1)})
    values = [sum(b*clamp(a+t*z,2*a) for z,a,b in axes) for t in knots]
    assert all(q >= Q for q in values)
    assert [t for t,q in zip(knots,values) if q == Q] == (
        [F(-1,2)] if vertical else [])
    assert values[0] > Q and values[-1] > Q

vol = [2*w*h for z,w,h in rows]
assert max(vol[0], sum(vol[:2]), sum(vol[3:]), vol[4]) < Q
assert min(sum(vol[:3]), sum(vol[2:])) > Q
print("86 cells and 138 triangles certified")
```


The axis calculation uses the interval capture function $\operatorname{clamp}(a+\tau z,0,2a)$ with $a=H_z$ and the multiplier $r_z$ for the vertical direction, or $a=r_z/2$ and multiplier $2H_z$ for the horizontal direction. The cap sum is affine between its displayed finite knots and constant on the two unbounded intervals. The check therefore gives the unique vertical minimizing tilt $-1/2$ for a positive vertical normal; reflection gives the other orientation. Pure-base caps through the origin have mass at least the smaller of the two closed side sums checked above. Parallel reduction to through-mark caps proves the depth at the origin. At every other base an appropriate closed outward pure-base cap gives a strict upper bound below $Q$ by the same arithmetic. At base zero the two vertical caps cover the whole fiber, so its depth is everywhere at most $Q$. This proves the asserted actual maximum.

For the tent path the width stays fixed and the height multiplier remains positive for small $t$, so compatibility persists. Its sampled shrink speeds are $(0,3,2,1,0)$, giving $\sum_z r_z h_z=1223/200$. For the one-node path, the successive height differences become $9/800-t,-3/800+t,-3/800,-3/800$ and are nonincreasing when $t<3/400$. Its weighted speed is $r_{-1}=51/50$. Both old vertical caps cut strictly between the roof points of each moving rectangle for small $t$. Each loses one strip of height $th_z$ while the total loses two. The fixed caps still cover the base-zero fiber and the strict pure-base upper bounds persist at all other bases by continuity. Hence the new global raw maximum is at most $Q-At$ and
$$
\frac{Q-At}{M-2At}-\frac QM
=\frac{At(2Q-M)}{M(M-2At)}<0 .
$$
